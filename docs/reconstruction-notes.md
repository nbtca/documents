## 打磨轮已完成（2026-08）

### 平台与性能

- **全站中文化**：`lang: zh-CN`；搜索、目录、上/下一页、最后更新、明暗切换、回到顶部、编辑此页、404 等主题 UI 文案全部中文。
- **中文搜索可用**：本地搜索的 miniSearch 默认按空格分词，中文整句成一个 token，等于搜不到。改用自定义 CJK 分词后，「维修」「第二课堂」「志愿者时长」等查询均能命中且排序合理。代价是搜索索引增大，但它只在用户点开搜索框时才加载。
