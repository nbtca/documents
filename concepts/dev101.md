# DEV101

DEV101 是 NBTCA 面向社内成员的开发主题讲座与分享系列，侧重编程与工程实践；与面向全校、讲计算机基础的 [CA101](./ca101) 相区分。

本站存档里的一处留痕：2025 年 12 月一次[技术分享会](./tech-talk)的[会议纪要](/archived/2025/2025.12.26NWDC)提到「补充 DEV101 会议缺失内容」——原会议音频缺失，相关的 GitHub Education 认证教程已另行补充。
