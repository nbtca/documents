## 附：当天跑的那套系统

上面照片里屏幕上的登录页，来自协会自己写的一套竞赛系统。它连同题库和数据库备份一起收在同一个文件夹（`第五届计算机知识竞赛2012/CCKC`）里，是档案袋中现存最早的一份协会自研软件。

**技术栈**：PHP + MySQL，用的是当时国内常见的 ThinkPHP 框架。入口分两个——`index.php` 挂 `Contest`（考生端），`admin.php` 挂 `admin`（阅卷端）。配置文件里有 `Stime` 和 `Etime` 两项，是答题的起止时刻。

**数据库**：备份文件是 phpMyAdmin 3.5.1 导出的，落款时间 **2012 年 12 月 1 日 13:44**——比赛前一天下午。运行环境记在文件头里：MySQL 5.5.24、PHP 5.3.13。

`player` 表的字段说明了这套系统能做什么：

| 字段                                 | 作用                                       |
| ------------------------------------ | ------------------------------------------ |
| `choiceAns`                          | 一个 66 位的字符串，一位存一道客观题的作答 |
| `textAns1` / `2` / `3`               | 三道主观题的答案                           |
| `ChoiceSco`、`TextSco1`–`3`、`score` | 客观题自动判分，主观题分项打分，再合成总分 |
| `isOnline`、`isReady`、`isJudged`    | 考生是否在线、是否就绪、是否已被阅卷       |
| `judger`                             | 这份卷子由谁阅                             |

也就是说：客观题机器判，主观题分给不同的人在后台阅，系统还盯着谁在线、谁交了、谁的卷子还没人看。`admin` 表里留着七个阅卷账号，其中李济轩、高恒修两位在两年前[第三届知识竞赛的工作名单](/archived/2010/3rd-knowledge-contest-duties)上就已经是判卷人。

**题库**是四个 XML 文件：单选（`Schoice.xml`）、多选（`Mchoice.xml`）、判断（`TorF.xml`）、简答（`Tquestion.xml`）。判断题文件的头注写着 `Created on : 2010年10月5日` ——这套系统比第五届早了两年，第三届那会儿就在了。
