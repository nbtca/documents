# 致协会每一位成员

〔档案里另有一份“2013 下计算机协会学期总结”，正文与本篇几乎相同，仅个别用词有出入。〕

时间过得真快，这学期也非常短暂。在计算机协会的第三年，对这个协会有着特殊感情的我此刻感触很深。早在上学期末的“会长说”一文中我曾说过从这学期开始我将退居幕后，逐步退去协会会长的职务，事实我也是这么做的，我尽量避免在协会大小事务上担任重要的工作。我希望的是更多大二大一的在协会有责任心有能力的干部们锻炼起来、涌现出来,逐步逐步开始由他们承担协会的事务，这方面我在执行的时候刚开始他们很不适应，跟我当年接学长们事情的时候一样迷茫，什么都得来问。事情做得不好，或者表现出来的情况不如人意还要抱怨、烦躁。但总体的趋势是，他们对协会的归属感在增加，他们对协会大小的业务越来越熟悉，遇事抱怨、烦躁这种态度在转变。

2013下的本学期当算我在协会的尾声了，学期初的时候我们并没有跟风其他社团一样提前去下班级，纳新结束的那天晚上我们顺便去了一下信息大一自习的教室，简单介绍了一下我们协会，当天的报名情况很好，有一百多名大一新生报了我们协会，这个结果足足让我们振奋了几天。纳新后为迎合信息学院教学安排，期中考试前不进行任何社团活动，我们不得不把协会纳新后的第一次新成员动员大会放到了期中考以后。漫长的等待让大一的部分同学开始怀疑我们协会到底有没有活动，我们也无奈而既然是规定那肯定得遵守。期中考后终于找机会开了一次，那天人员到位情况挺好，我就在上面瞎讲了1个多小时，完了喉咙都哑了，能看到大家热情都很高还是非常欣慰。随后按照先前的协会计划，活动落实到部长，我们的单个活动都有具体的某个部长或某几个部长负责承办，大小的活动算起来也有不少，我已在协会的活动表中列出。总体就我会长而言，跟部长们的合作还是非常愉快的，虽然有些部长可能觉得我把他们坑了一把，有什么办法呢事情来了总要人去处理的，我没有可以要给谁多干点，不要焦躁，每一份付出都有相应的收获，现在的镇痛是蜕变的前奏。而部长们跟干事的合作我具体不是很了解，协会群里面部分新成员互动还是很热烈的，不知道部长们在部门开过几次会、开会的气氛又如何、究竟部长们教授了些什么，本该去做一些了解的但想想这是部长的事我没必要去干涉的也没有给定他们每次的活动产出，直接放他们空间让他们去带部门。我们的部长们总体上还是非常好地完成了本学期协会的全部任务，除了部分活动因为时间等种种原因没有展开，该办的活动都办了，我当然是希望他们每台活动都办得好点，能够一次次扩大协会的影响力，而我不能给他们太高要求，因为每次都是他们不同的人在筹办，都是第一次，活动办得好固然重要，不过每次活动都要以人才培养（人不带起来协会便死）和内部成员自我提升为基础（先要干部做活动的业务能力培养起来，其次内部成员都要学到东西，最后才看活动的好坏，活动不是给别人看的，是给自己协会的人办的（这里有些大一成员办活动不来就有点说不过去了），至少计算机协会是这样，而不是在做表面工作）。

写给大一新生的在这里，看到下面的这段文字是作为一个大三学长、协会会长给你们的一些过来人的想法或建议。首先非常抱歉，我虽然是作为计算机协会会长，但是我花在处理协会事务上的精力没以前大二的时候多了，很多情况下你们来问我事情我都推到相应的部长那边去，跟你们交流的次数也很少，不知道你们的想法不知道你们在协会想要学到的东西究竟学到了没有。这是本人比较愧疚的地方，说白了这是部长的事，部长是你们直接的联系对象，你们的事由你们的部长们全权负责。还记得在学期中我在协会动员上说的么，在协会有没有白来全取决于你自己，这点跟你们上学有点不同，没人逼你去干什么，大家都是同学就算长一岁两岁也不能用逼的，全看自身的。此外，我给你们提的一些硬性要求让你们去平台里编程、去图书馆借专业方面的书看、有问题去跟学长探讨，你们有这么做么？期末让你们别挂科，都复习得怎么样了，都准备好了么，如果答案是没复习，还来得及，微积分三天可以拉起，其他课也一样，你就得有股霸气，多少时间之内拿下它们，死磕到底！什么是霸气？是抽几根烟那叫霸气？是骨头里有气。随着大学的推进，你们会发现大学越来越像社会，而我们要做的就是提前做好准备，完善自己，学好专业技能，回报xxx（这个我习惯现实地解读为混口饭吃，首要解决的是走上社会的吃饭问题）。学长想跟你们交待的事情太多了，先说到这。小结，珍惜大学的四年时间把该学的都学了，别挂科，学好专业知识，（当你们猛然发现你缺乏某个技能的时候你已经大三大四了）不要四年下来啥不会；尽可能的体验生活，多出去走走（多几次说走就走的旅行），大学可以谈场恋爱（不反对不鼓励）（别骗对方跟你上床），谈恋爱不是拼富拼帅拼爹，展示出你的能力、潜力。以上是学长自己的一些感悟一并在这里说了。出于对协会人才的储备，你们要多与部长们去沟通，做事勤快些，干部是学习锻炼出来的也是累出来的。真心希望你们在协会能学些东西回去，不论是组织管理还是计算机知识。

2013年对协会来说是不平凡的一年，我在协会任职一整年，我们有太多辛酸和汗水，此刻我用什么话都无以言表了。感谢这一学年协会上上下下各位成员的辛勤付出，感谢所有帮助过我们的人，星星之火可以燎原，你们的绵薄之力也是对协会最大的支持！在这新年的第一天祝大家新年快乐，复习顺利，考试全过，早日与家人团聚，也预祝大家在不久后到来的中国农历新年幸福美满、合家欢乐！新的一年协会还要以它的步伐继续发展，而一届一届不断被称为老人的人也有要自己的步伐去做自己的事了。具体下学期的计划我们寒假再议。

会长 许益灵

2014/1/1

## 整理说明

〔这封信是[半年前那篇“会长说”](/archived/2013/2013-06-29-presidents-note)的下半场。那篇里他宣布要退到幕后、把活动落实到部长；这一篇是他回头看这半年的执行结果，也是档案里少见的、把交权过程写下来的文字。

他记下的三个阶段很具体：部长们起初“很不适应，跟我当年接学长们事情的时候一样迷茫，什么都得来问”；接着是“事情做得不好……还要抱怨、烦躁”；最后“他们对协会的归属感在增加……遇事抱怨、烦躁这种态度在转变”。而他自己的做法是刻意的不介入——“不知道部长们在部门开过几次会、开会的气氛又如何……本该去做一些了解的但想想这是部长的事我没必要去干涉的”。

那句括号里的话是这封信的核心，也是他留给协会最常被引用的一句：**“每次活动都要以人才培养（人不带起来协会便死）和内部成员自我提升为基础”**，接着解释了顺序——先是干部办活动的业务能力，其次是内部成员学到东西，“最后才看活动的好坏，活动不是给别人看的，是给自己协会的人办的”。

信里还留下一件别处没有记载的事：因为信息学院规定期中考前不办社团活动，纳新后的第一次动员大会被推迟到期中考之后，“漫长的等待让大一的部分同学开始怀疑我们协会到底有没有活动”。社团节奏被教学安排卡住——这件事在别处只能从活动日期的空档间接看出来，这里是直接写明的。

而那句愧疚——“跟你们交流的次数也很少，不知道你们的想法不知道你们在协会想要学到的东西究竟学到了没有”——与 2017 年[会长公开信](/archived/2017/letter-to-all-members)里的自省、2007 年[最早那份总结](/archived/2007/2007-h1-work-summary)里的“组织层与会员之间缺少有效的沟通”，是同一个问题在不同年份的三次现身。他指出的另一个瓶颈——一年带不出接班人——[次年的工作报告](/archived/2015/2014-2015-work-report)又原样重复了一遍。〕
