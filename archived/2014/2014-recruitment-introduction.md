# NIT 计算机协会（2014 纳新介绍）

计算机协会成立于2002年3月，经上学期末的面试选拔，第13届的成员们正以崭新的姿态面对新一学年的挑战。协会部门经多次改革现由活动部、技术部、宣策部组成。协会入会门槛低，可以教会你一些基础的计算机知识。当然我们也有大神级别的学长，各种软硬件方面的问题都不成问题。

协会有一系列的品牌活动，比如理工服务日、计算机知识竞赛、电子产品导购与维护讲座、电路焊接、日常维修等。理工服务日，协会的成员联合各大电脑品牌维修服务站的工程师为理工所有同学和老师提供维修、清灰等服务，并解答同学们使用电脑过程中遇到的各种问题。计算机知识竞赛更是有学分小票和奖状，获奖的同学不但可以申报第二课堂学分，还能拿到各种奖品。电路焊接也是为那些可能一辈子都不会接触电烙铁的同学提供一次宝贵的机会，也为信工专业的同学提供练习的机会。通过这些活动，我们旨在加强同学们之间的交流与沟通，共同分享在参与活动的过程中所学习到的经验和感悟。加入计算机协会，学会给自己电脑重装系统绝对不是问题，如果你还有兴趣，我们这里有循迹小车、光立方、四翼飞行器等玩意可以和学长们一起研究学习。〔四翼飞行器这个念头[前一年的新社员大会宣讲](/archived/2013/2013-freshman-briefing)里就有了——当时协会有个“自控组（筹备中）”在做多旋翼飞行器的姿态控制。〕欢迎同学们在协会纳新的那天踊跃报名，加入计算机协会这个大家庭。
