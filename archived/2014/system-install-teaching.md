# 知识结合实践——2014 年装系统教学

## 信息学院计算机协会 2014 年装系统教学

为了让大学生对基本的计算机知识有所了解，信息学院计算机协会在11月2号13:30于南教学区进行了装系统教学，当天计算机协会会长诸葛瞻、副会长陈聪和技术部干部都到场对新生进行了指导，此次培训的对象是14级新生。

<Figure src="../assets/sysclass-2014-group.webp" alt="八九名学生紧紧围成一圈，挤在一台 MSI 笔记本前；居中一人手放在触控板上操作，其余人俯身盯着屏幕，背景是书架" caption="“分成了 4 组，每组都有一个负责人进行指导”——一组就是这么一圈人围着一台机器。" date="2014-11-02" source="协会照片档案" wide />

因为参加本次活动的人数较多，所以参与的新生们分成了4组，每组都有一个负责人进行指导。新生们对装系统这个活动表现出了极大的兴趣，所有人都紧紧地盯着负责人的每一步操作，负责人也很认真地讲解每一个步骤。活动现场，新生们踊跃提问，负责人耐心仔细地解答，整个活动就在欢乐的氛围中圆满结束。

就像计算机协会会长所说的“作为信息学子，装系统是大学四年要学会的基础技能。”通过这次培训，新生们对计算机的了解更近了一步，对计算机有了更浓厚的兴趣，同时，对计算机协会也有了更深一步的了解。
