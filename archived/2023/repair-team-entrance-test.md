# 维修队摸底测试（2023.10.14）

浙大宁波理工学院计算机协会维修队摸底测试

命题人：戴上博　　命题时间：2023.9

## 卷首说明

这是浙大宁波理工学院计算机协会维修队摸底测试，我们制定这套卷子意在**了解新社员的基本知识储备以及考察对信息检索的能力**。

本套试卷共 11 题，其中客观题 9 题，主观题 2 题，共计 100 分。内容涉及软件和硬件两部分，大部分题目偏常识，能够较轻松地回答，少量题目会涉及到知识应用并结合自己经验，需要你稍加思考后再作答。

**本试卷没有指定合格分数，请放心作答**！

出题时间仓促，题目若有错误可指出并核实后加分！

祝你作答顺利！

### 重要提醒

1. 试题册共 4 页，发到试题后请检查是否有漏印、缺页、字迹不清等问题，如有请立即提出
2. 本试卷作答时间为 30 分钟，请认真作答
3. **你可以借助互联网等工具查阅所需要的信息，也可以手动尝试来完成此试题**
4. 查阅资料时，请仔细甄别内容是否对你或你的计算机有害
5. 严禁替考、抄袭等作弊行为

## 一、客观题（65 分）

本部分包含选择题与填空题。选择题包含单项选择和多项选择，其中 1-3 为单项选择 5 分一题，答对即得分；4-7 为不定项选择（即正确答案数量 ≥1）10 分一题，答错得 0 分，部分正确得 5 分，完全正确得 10 分；8 为单项选择 1 分一题。9 为填空题，1 分一题。

## 二、主观题（35 分）

本部分有两小题，其中第 10 题 10 分，第 11 题 25 分，请使用文字或其他方式详细说明解答过程。

**10.**（10 分）你的电脑里含有一块 512GB 大小的 M.2 的硬盘，分区表为 GUID 格式，其中 300MB 划分给了引导分区（0 号分区，ESP 格式），80GB 划分给了分区 C（1 号分区，系统分区，NTFS 格式）剩下的都划分给了分区 D（2 号分区，NTFS 格式）。某一天你发现分区 C 空间不足，分区 D 存放了大量软件但仍旧充足。分区 C 无论怎么清理都无法释放空间，怎么做能方便地解决此问题？

提示：可借助 Windows PE 等工具完成

> **参考答案**：下载一个 Windows PE（网上选一个好用的），使用一个空 U 盘，把下载的 Windows PE 烧录到 U 盘里面。重启电脑，快速连续按 BootMenu 对应的快捷键（部分电脑在侧边，需要关机后按一下该按钮；也有部分电脑的快捷键和 BIOS 做在一起，因电脑型号而异），使用键盘的 ↑、↓ 按钮选择 U 盘并回车。进入系统后，打开 DiskGenius 磁盘分区工具，点击分区 D，调整分区大小，分区前输入 70GB-合并到 C:，分区后不填，确认分区 C 和分区 D 的数据都已备份后点击开始。完毕后可重启电脑，若可直接进入 Windows 系统，那已经完成了，若再一次进入了 Windows PE，则需要重启再一次进入 BootMenu，将 Windows Boot Manager 通过键盘的 ↑、↓ 按钮放到第一位。保存后退出即可进入 Windows 系统。检查分区 C 和分区 D 的文件是否有错误，如有请将备份好的文件复制进来。

**11.**（25 分）假如有人希望你能按照下列需求给他推荐一台笔记本电脑，你会选择哪款？并从中央处理器、图形处理器、内存、硬盘、重量等多方面阐述理由

需求：

- a) 该同学为 23 届新闻学专业学生，有大量音视频存储、剪辑、渲染需求；
- b) 喜欢玩 CS-GO，英雄联盟，GTA5，某二字开放世界冒险 RPG 等；
- c) 该同学因高中时期学习过于认真患上脊柱侧弯；
- d) 计算机本体预算不超过 ¥8000。

（本题无标准答案，合理即可）
