# 计算机知识竞赛成绩统计

原表逐人记了姓名、联系方式、成绩与奖项。当年颁奖本就是公开的，因此获奖名单照录；其余参赛者的个人分数不逐条列出，只给汇总——这是一份十余年前的社团竞赛成绩，没有必要把每个人的分数留在网上。

## 汇总

| 项目     | 数值 |
| -------- | ---- |
| 参赛人数 | 73   |
| 最高分   | 77   |
| 最低分   | 26   |
| 平均分   | 47.8 |
| 中位数   | 46   |
| 获奖人数 | 10   |

题目难度可以从分布看出来：平均 47.8 分、中位数 46 分，三等奖的门槛落在 61 分。
