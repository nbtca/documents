落款：浙江大学宁波理工学院学生社团联合会（另一落款单位与红章按原件保留在上方扫描件中）。

〔此前[组织与沿革](/about/organization)记的 2002 年 3 月，依据是协会自己写的[老版简介](/archived/2009/club-introduction-legacy)与 [2013 年简介](/archived/2013/club-introduction)；这张证书把同一个日期从“自述”变成了“注册记录”。

其余各栏也与同期材料对得上：社长许益灵见于[第十二届换届公示](/archived/2013/12th-handover-result)与[2014 年导购讲座策划](/archived/2014/buying-guide-lecture)，指导老师周金兰见于同一份公示。注意登记的全名是“**学生**计算机协会”，与协会对外常用的“计算机协会”略有出入。〕

## 2016 年的那一份

档案里还有第二份证书。它没有单独存档，而是拍成照片插在 2017 年那次星级评比的《社团工作报告》里。

<Figure src="../assets/club-registration-2016.webp" alt="一张带橙色花边的证书照片，摆在键盘上拍摄；抬头是浙江大学宁波理工学院校徽与校名，标题“学生社团登记证书”，右上角“证书号第　号”一栏空着；正文各栏为手写填写" caption="拍照存下的第二份证书。证书号那一栏没有填。" date="2016-11" source="原件插图" />

| 栏目     | 填写内容                           |
| -------- | ---------------------------------- |
| 社团名称 | 浙江大学宁波理工学院学生计算机协会 |
| 挂靠单位 | 信息科学与工程学院社联             |
| 社长     | 刘宽                               |
| 指导老师 | 王朗                               |
| 成立时间 | 二零零二年三月                     |
| 发证日期 | 二零一六年十一月                   |
| 有效期至 | 二零一七年十一月                   |

〔隔了三年，四栏变了、三栏没变。成立时间仍写“二零零二年三月”——两份独立的校方文件填的是同一个日期。

变的三处各有出处：社长刘宽见于同年[纳新宣讲](/archived/2016/2016-recruitment-briefing)的封面与核心组成表；指导老师由周金兰换成王朗；挂靠单位由“信息科学与工程学院**团委**”改为“信息科学与工程学院**社联**”。

值得注意的是挂靠单位这一栏：2016 年 11 月的登记证书上仍写“信息科学与工程学院”，而同年 10 月的[纳新宣讲](/archived/2016/2016-recruitment-briefing)已在讲“数据学院”的事——[学院变迁](/concepts/college)那条线上，校方文书与协会自称并不同步。〕
