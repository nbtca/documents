## 课堂内容：档案里剩下的东西

计划表上“课堂内容　进度”两栏是空的，但档案袋另一处（2008 年度／陈龙／计算机知识／讨论课材料）留着当时备课用的一整套材料，文件名本身就是课表：

- **`3.1电脑选购DIY.ppt`、`3.2电脑选购DIY.ppt`、`3.3 电脑组装DIY.ppt`** —— 编号说明课是按节排的，第三节讲选购与组装
- **`组装后续工作(BIOS设置).flv`** —— 一段 28 MB 的教学视频，装完机之后怎么设 BIOS
- **`CPU参数全解.doc`**
- 一组笔记本专题：常见接口、端口、显卡选择、无线网卡、摄像头、存储卡读写器、周边设备术语、硬件术语、基本术语，外加一篇《高中端笔记本电脑包品牌》

同一年度的另一个文件夹（苏凯辉／验机）里是四个绿色版工具，那是当年验机的全部家当：

| 工具     | 版本           | 用途                               |
| -------- | -------------- | ---------------------------------- |
| CPU-Z    | 1.40.5 汉化版  | 看 CPU、主板、内存的真实型号与参数 |
| EVEREST  | 4.00.1053 Beta | 整机硬件信息与传感器读数           |
| HD Tune  | 2.53           | 硬盘性能与健康检测                 |
| DisplayX | ——             | 屏幕坏点与显示效果检测             |

〔“验机”是买了新机器之后当场核对配置、检查屏幕和硬盘——2008 年替同学做这件事，用的就是这四个。今天[软件仓库](/repair/tools)里那份清单要长得多，但要办的事没变：认硬件、测硬盘、验屏幕。〕
