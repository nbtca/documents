# 2008：重新成立维修队

## 一、《计算机协会关于成立计算机维修队的报告》

### 现状分析

计算机协会自上学期由信息分院社团联合会统一管理以来，得到了信息分院领导的大力支持，无论是我们协会内部的每周课堂，还是信息分院的的信息文化节，我们都充分策划，举办的有声有色。

在学校很多同学对计算机基础知识了解不够，当电脑出现问题时无法准确的解决。而校内电脑店又处于垄断地位，收费偏高，修理也需要等很长时间，同时电脑坏了无法及时修理延误同学们学习工作的时间。

针对以上情况，计算机协会准备重新成立计算机维修队，我们需要一名石麟二楼计算机中心的老师做我们的指导老师，希望能够得到老师的帮助与技术指导。

同时我们也可以帮助老师完成一些简单的任务——比如机房的系统维护。我们也可以学到一些知识，积累一些经验，得到一些锻炼的机会。

培养坚持不懈无私奉献的精神是当代大学生所必须的，在实践中我们能培养一种专研精神，，增强我们的实践能力，同时我们理论与实践相结合，学会与人沟通、相处，在维修队中锻炼自己，让大学生活过得更加丰富多彩。

计算机协会宗旨：为了更好的服务同学，普及计算机基础知识，解决计算机应用中的实际困难，丰富大学生课余文化生活

信息分院计算机协会

〔“**重新**成立”这三个字要紧。[2010 年的解散通知](/archived/2010/repair-team-dissolution-notice)说维修队 2003 年成立、到那时做了七年；这份报告说的是 2008 年秋天把它重新立起来。两件事并不矛盾——[协会简介（老版）](/archived/2009/club-introduction-legacy)记的正是 2008 年十月办“维修队招贤赛”选出十名队员并开始培训。

报告里的交换条件也值得一提：请计算机中心的老师做指导老师，协会则帮忙做机房的系统维护。〕

同一批材料里还有一份措辞更松散的稿子（《关于计算机维修队》），是上面这份报告的草稿，理由逐条列出，未成文。

## 三、两张单据

维修队自己设计了两张表。一张挂在电话边上，用来接单：

| 接单时间 | 电话 | 机主姓名 | 寝室 | 症状简介 | 处理人员 |
| -------- | ---- | -------- | ---- | -------- | -------- |

原件抬头写“计算机协会维修队报修记录单”，下面是几十行空格。

另一张跟着机器走，用来记这一单怎么处理的：

| 栏目         | 内容                                         |
| ------------ | -------------------------------------------- |
| 接单日期时间 |                                              |
| 处理人员     |                                              |
| 机主姓名     |                                              |
| 联系电话     |                                              |
| 问题描述     | 机主的描述：<br>现场了解情况：<br>处理方法： |
| 处理时间     |                                              |

〔第二张表里“问题描述”拆成三行，是这两张纸上最见功夫的地方：**机主的描述**、**现场了解情况**、**处理方法**分开写。机主说的和你到场看见的常常不是一回事，2008 年的这张表已经把这件事写进了格式里。

这套字段此后一直在：[2009 年暑期实践](/archived/2009/2009-summer-practice)带下乡的服务记录单、[2011 年维修技术部的值班记录单](/archived/2011/repair-duty-roster)、直到今天的[在线工单](/repair/weekend)，问的都还是这几样。〕
