## 一、计算机网络基础知识

### 按地理范围分类

- **局域网（LAN）**：覆盖范围为几百米到几公里，局域网内传输速率较高，误码率低，结构简单容易实现。具体标准是美国电气工程师协会制订的 IEEE802 系列标准。
- **城域网（MAN）**：通常是使用高速光纤的网络，在一个特定的范围内（例如校园、社区或城市）将不同的局域网连接起来，构成一个覆盖该区域的网络，其传输速率比局域网高。
- **广域网（WAN）**：一般是在不同城市之间的 LAN 或者 MAN 网络互联。

〔讲义里专门解释了“校园网”：“在一个学校范围内的计算机网络通常我们称为校园网。实质上它是由若干个局域网连接构成的一个规模较大的局域网，也可视校园网为一种介于普通局域网和城域网之间规模较大的、结构较复杂的局域网络。”〕

### 局域网的组成

局域网可划分为网络硬件系统和软件系统两大部分。

- **服务器**：又称主机，网络中为其它计算机提供服务的计算机，网络中可共享的资源大都集中在服务器中。
- **工作站**：又称客户机，网络中共享网络资源的计算机。

### 七种网络设备

讲义逐个讲了下面这些设备，并标出它们各属网络体系的哪一层：

| 设备                   | 层         | 讲义里的说法                                       |
| ---------------------- | ---------- | -------------------------------------------------- |
| 网络适配器（网卡 NIC） | 数据链路层 | 插入主板总线插槽的硬件，用于将用户计算机与网络相连 |
| 中继器 Repeater        | 物理层     | 把接收到的弱信号分离，再放大以保持与原数据相同     |
| 集线器 Hub             | 物理层     | 分切换式、共享式和可堆叠共享式三种                 |
| 网桥 Bridge            | 数据链路层 | 一个局域网与另一个局域网之间建立连接的桥梁         |
| 交换机 Switch          | 数据链路层 | 可看做是多端口的网桥                               |
| 路由器 Router          | 网络层     | 用于连接多个逻辑上分开的网络                       |
| 网关 Gateway           | 应用层     | 连接不同类型而协议差别又较大的网络时选用           |

### TCP/IP 与 IP 地址

- **TCP**（Transmission Control Protocol）传输控制协议，用于保证被传送信息的完整性。
- **IP**（Internet Protocol）网际互连协议，负责将消息从一个地方传送到另一个地方。

IP 地址为 Internet 上的每一个网络和每一台主机分配一个网络地址，格式为 `XXX.XXX.XXX.XXX`，每段 0~255。讲义按当时的分类法讲了 A、B、C 三类地址的范围。

### 域名系统 DNS

DNS 采用分层次结构，入网的每台主机都可以有一个“主机名.机构名.顶层域名”形式的域名，从左到右域的范围变大。讲义还列了一张顶级域名对照表（com 商业类、edu 教育类、gov 政府部门、org 非盈利组织……）与中国互联网络的二级域名体系（ac 科研机构、edu 教育机构……）。

### 线序

- **T568B**：橙白-1，橙-2，绿白-3，蓝-4，蓝白-5，绿-6，棕白-7，棕-8
- **T568A**：绿白-1，绿-2，橙白-3，蓝-4，蓝白-5，橙-6，棕白-7，棕-8

<Figure src="../assets/netcable-pinout-chart.webp" alt="568B 与 568A 的色序对照表：上行按 1 至 8 依次列白橙、橙、白绿、蓝、白蓝、绿、白棕、棕，下行列白绿、绿、白橙、蓝、白蓝、橙、白棕、棕；两行之间注明直通线与交叉线各用在何处，右侧画出水晶头正视图，图角有“有图小站”水印" caption="讲义所附的色序对照表。水印是当年制作者取图的来源。" source="原件插图" wide />

### 三种网线

| 类型                    | 两端线序   | 用来连                                                             |
| ----------------------- | ---------- | ------------------------------------------------------------------ |
| 直通线 straight-through | A—A 或 B—B | 主机到交换机/集线器，路由器到交换机/集线器                         |
| 交叉线 crossover        | A—B        | 交换机到交换机，集线器到集线器，主机到主机，路由器到路由器或到主机 |
| 反转线 rollover         | A—A 的反序 | 主机到路由器控制台串口                                             |

### 制作步骤

1. 把双绞线一端插入压线钳剥线的缺口，伸出 2-3cm，稍握紧慢慢旋转一圈划开保护胶皮，拔下胶皮，注意不要割开裸露线的塑料胶皮。
2. 剥除外包皮后见到 4 对 8 条芯线。每对缠绕的两根由一种纯色芯线加一条白色相间芯线组成，四条全色芯线为橙、绿、蓝、棕。
3. 把 4 对芯线并排分开，按 A 标准或 B 标准的顺序排列，每条拉直、相互分开不重叠，用压线钳剪齐——长度要够芯线刚好放进水晶头到底，又不至于外露。

   <Figure src="../assets/netcable-step-order.webp" alt="一只手捏着剥好外皮的网线，八根芯线已解开、理直并排成一列" source="原件插图" />

4. 左手握水晶头、金属片一面朝上，把剪齐的 8 条芯线对准开口并排插入，以最左一根作线序第一根，一定要各条不弯曲且插到底。

   <Figure src="../assets/netcable-step-insert.webp" alt="手指捏住一枚水晶头，八根排好序的芯线正插入其中，侧面可见每根都顶到了头部" source="原件插图" />

5. 把水晶头放入压线钳压线缺口，放到底，再确认顺序没在插入时打乱，然后用力压下手柄，往往会听到“咔”的一声。

   <Figure src="../assets/netcable-step-crimp.webp" alt="插好芯线的水晶头放进压线钳的压接槽中，一只手握着钳柄正要压下" source="原件插图" />

6. 另一端按相同方法，按直通/交叉/反转的相应标准做。

   <Figure src="../assets/netcable-step-done.webp" alt="压接完成的线头特写：灰色外皮被卡在水晶头尾部的三角卡扣下，八根芯线在头内并排到底" source="原件插图" />

7. 两头都做好后用测线仪测：8 个指示灯按对应顺序绿色闪过即成功。直通线是 1-8 号灯依次闪，交叉线是 1—3、2—6、3—1……的顺序。

## 整理说明

### 2018 年那版改了什么

2018 年 4 月又讲了一次（[那一场的新闻稿与经过](/archived/2018/cable-making-workshop)）。讲义压到 17 页，第一部分那套网络基础知识全部删掉了，直接从网线讲起；而第二部分“做一根网线”的七步，与 2016 版**一字不差**。

改动集中在两处：

- 封面多了个联署单位“**联想精英大侠**”——幻灯片专门用一页介绍：“由世界 500 强企业联想集团创立……为在校大学生开拓一条新型的创业和社会实践机会”。这是校企合作进课堂的一次记录。
- 前面补了两页讲**双绞线的种类**：非屏蔽（UTP）、屏蔽（FTP/STP）与双屏蔽三种，以及五类线与六类线的区别。

〔[活动统计](/archived/2017/2016-2017-activity-stats)与[工作报告](/archived/2018/2017-2018-work-report)记下了“办过一场网线制作教学”，[当年的活动总结](/archived/2016/hands-on-workshops)记下了现场——“有些同学一次性就做成功，而有些同学失败了好几次但是仍然继续坚持努力去完成”。讲了什么，则要看这份课件。

它先讲原理，后动手：前半从局域网讲到 DNS，后半才让人拿起压线钳。做线七步写到伸出 2-3cm、听“咔”一声、8 灯依次闪，照着就能做出一根。

2013 年的[电脑知识普及风暴](/archived/2013/2013-04-knowledge-storm-plan)已经摆台子让同学自己做网线头，2016 与 2018 两年排成正式教学。隔了五年，那七步一字未改；变的是 2018 年拉来了联想的校园团队联办。
