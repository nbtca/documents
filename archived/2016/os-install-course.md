2016 年 10 月，协会的装系统教学不再只有一份课件，而是**一整套**：Windows 一份、Ubuntu 一份、VMware 装 Mac OS X 一份，外加一份讲硬盘分区原理的“总”。封面都印着同一行——“各类电脑系统教学之——”。

## 一、这套课教到哪

### Windows

标准安装与 ghost 安装两条路，落到 U 盘 PE、光盘、硬盘三种介质。讲义讲了怎么用大白菜/老毛桃做 PE 启动盘、进 BIOS 把 U 盘设成第一启动项、装完之后激活、装驱动（推荐驱动精灵）、装 Office 与 WinRAR。选 U 盘要点明了容量：“64 位的 Windows 7 旗舰版系统安装盘是 3.11GB……WIN 7/8.1/10 系统需要用 4.7GB 以上的 U 盘”。

### Mac OS X（在 VMware 里）

最费功夫的一份。先教装 VMware 10——“安装完成显示需输入密匙，这时候需打开 VMware10 压缩包，里面的 sn.txt 文件里的 2 个序列号任意复制一个进去”——再讲怎么用一个解锁补丁让 VMware 支持 Mac OS X，最后在虚拟机里装上 Mac OS X 10.9，装完 VMware Tools。

〔这属于当年常说的“黑苹果”，在非苹果硬件上以非官方方式运行 macOS，与苹果的许可条款相抵触。此处只记下协会教过这一课，不复述其中的补丁与破解细节。这一份课件有 42 张操作截图，从填序列号、解包解锁工具一直拍到装完 VMware Tools，逐张收录等于把这套做法重新发布一遍，故整份未收。〕

### 硬盘分区原理（“总”）

一份不讲操作、只讲原理的课件：主分区与扩展分区、FAT32 与 NTFS 的区别、低级格式化与高级格式化的含义，还列了一张各品牌进启动菜单的快捷键表（华硕主板 F8、联想笔记本 F12、技嘉主板……）。这一份与 2011 年[故障处理讲座](/archived/2011/fault-handling-lecture)里分区与格式化那几页讲的是同一套知识。

## 二、镜像从哪来：协会自己的文件服务器

这套课件最值得留意的一处细节，藏在下载链接里。VMware 那份写着：

> 下载链接：`ftp://10.80.6.166/vmware10.rar` 内附注册码

> BT 链接：`ftp://10.80.6.166/MAC10.9.torrent`

`10.80.6.166` 是一个校内网地址——**2016 年，协会已经在自己的服务器上放系统镜像和软件供成员取用了**。这是[基础设施](/about/infrastructure)那条线的早期一环：今天协会的[内网镜像站 i.nbtca.space](/repair/tools)（系统镜像、维修工具）做的是同一件事，只是从一个 FTP 地址变成了一个有索引的站点。

〔这套课件回答的是一个容易被低估的问题：协会到底教到多深。“装系统”听上去是件小事，但 2016 年这套课的跨度并不小——Windows、Ubuntu、Mac OS X，从最普通的重装一直讲到在虚拟机里跑黑苹果。对一个学生社团来说，这是相当有野心的技术面。

自建 FTP 是最有分量的一条。`ftp://10.80.6.166` 出现在课件里，说明 2016 年协会已经在校内跑着一台放镜像的服务器。本站[基础设施](/about/infrastructure)一页讲的是今天的 i.nbtca.space 镜像站与那一串 Cloudflare Workers 服务，而这个内网 FTP 地址，是同一件事早了近十年的样子——协会“自己搭东西给自己用”的习惯，从这里就能看到。

装系统这门课比大多数活动都持久。从 2014 到 2016，年年在办，[2014 通讯稿](/archived/2014/system-install-teaching)里会长诸葛瞻那句“作为信息学子，装系统是大学四年要学会的基础技能”，把它为什么一直办说清楚了：这不是表演给外人看的活动，是协会认定新生该会的一项基本功。

最后，2014 那四句座右铭值得留着。它们和[平安夜那十七句话](/archived/2014/christmas-eve-notes)是同一种东西——在一份本该是纯技术的课件里，协会还是给每个带组的人留了一行自己的话。“不服你来打我啊”，一句就把那间机房里的气氛留住了。〕
