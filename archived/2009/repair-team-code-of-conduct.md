# 维修队工作守则（八大纪律八项注意）

1. 运作流程：同学甲 → 维修队助理 → 当天值班人员／维修队队长 → 大概解决方法
2. 值班人员在维修时做好填单工作，以备再次出现问题时查询。
3. 每周周末维修队助理将本周维修单上交技术部部长，供技术部部长整理，发布到论坛上，并总结后作为培训内容。
4. 禁止利用工作便利在电脑上安置木马、放毒。
5. 涉及到密码的地方，要让机主本人亲自输入（QQ，上网账号），避免以后不必要的麻烦。
6. 维修过程：
   1. 听取机主描述
   2. 翻查电脑
   3. 判断症状
   4. 想出对策（遇到不会的问题，如果可以上网去百度知道里搜索，如果不可以上网，可询问维修队队长或者技术部部长或者会长）
   5. 告诉机主，再进行操作（如果有多种对策，告诉机主利弊，让机主选择）
   6. 问题如果没有解决，回到第二步
   7. 解决，收工
7. 如果多次尝试，还是无法解决问题，记录问题后，收工，问题上报维修队队长。
8. 维修时要保证电脑内资料安全。
9. 只处理软件问题，遇到并判断为硬件问题，告诉机主去找专业维修人员。
10. 坚决不收报酬（礼物、请客吃饭、金钱等）。
