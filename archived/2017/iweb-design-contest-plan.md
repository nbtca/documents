# 第一届浙江大学宁波理工学院“iweb”网页设计大赛活动策划书

浙江大学宁波理工学院计算机协会

## 活动背景

每年 12 月初，学校会举行计算机程序设计大赛。ACM 队——作为浙江大学宁波理工学院的特色，也是我们数据学院的骄傲，负责历届计算机程序设计大赛的出题；学术部向来组织数据学院最具专业的活动，负责主办历届计算机程序设计大赛。

为丰富校园文化生活、点缀校园缤纷色彩，鼓励同学们对生活积极的观察与发现，提高学生审美能力以及对平面设计作品视觉传达的认识，激发学生创新和设计的潜能，发掘优秀网页设计人才；提高同学们的网页制作水平，使学生学习和实际工作联系起来，拟与计算机协会合作，一起举办第一届“iweb”网页设计大赛，带动更多的同学投入专业知识的学习中去。

## 活动目的

为了活跃校园计算机文化，提高广大同学对计算机网页设计兴趣，为广大计算机网页设计爱好者提供一个展示才华、相互交流的平台与机会，因此决定举办第一届浙江大学宁波理工学院“iweb”网页设计大赛。

## 比赛时间、参赛对象

- 竞赛时间：2017 年 5 月
- 竞赛地点：信息中心
- 参赛对象：所有在校学生，可个人参赛亦可最多五人组队参赛。

## 参赛规则

选手报名要求：

1. 本次大赛采取以小组或个人报名参赛的方式。（说明：获奖后奖状和奖品每队只有一份。）
2. 选手自由组合，小组成员控制在最多 5 人。
3. 务必在报名时填齐成员详细联系资料（包括邮箱等）。
4. 报名时需注明希望制作主题。

参赛者须在作品提交截至日期前将作品通过 ftp 或电子邮件提交到大赛举办方，并做好备份。

## 评奖规则

### 参赛要求

参赛选手自定一个站点名称，静态网页格式 html，动态网页可由 java 或 C# 或 php 编写。要求主题鲜明突出，创意新颖，页面结构美观，还可以具有一定的幽默效果。

### 设计要求

1. 作品内容健康向上，符合本次比赛作品征集要求；
2. 制作软件不限制，通过合理运用网页设计的各种技术，体现良好的艺术性和实用性；
3. 页面深度必须在 3 层左右，网页的总页面数不少于 6 页，全部文件的总容量不超过 50M（尽量少用音频视频文件）；
4. 要求能在 win2008 或 win7 及以上操作系统上运行。显示分辨率以 800×600 或 1024×768，网页采用 Internet Explorer8.0 以上浏览（请在作品中注明最佳浏览效果浏览器。）；
5. 使用简体中文字库系统；
6. 网页规模：网页的深度至少包括二级页面，以 4~7 个页面为适宜；
7. 作品中所有文件均要以字母或阿拉伯数字命名，包括（各文件夹、网页文件、图片文件、Flash 文件等等）文件名及其后缀名，不要用中文命名；
8. 作品制作规范符合要求；作品压缩包请一律采用编号加队名命名。
