# 微信推送大赛

本次大赛为浙江大学宁波理工学院计算机协会为团结协会内部成员，加强内部沟通的一次小规模赛事。

## 要求

参赛人员仅限于计算机协会五部门中的系统运维部、软件研发部、硬件开发部、综合事务部四部门（宣策部负责审核和发布）。非协会成员不得参加，不得寻求协会以外的成员帮助，一经发现，取消获奖资格。

## 流程

- 各部门最迟于 16 日中午 12 点将参赛人员姓名、班级汇报给会长
- 会长将于 16 日晚发布各部门顺序表
- 每位参赛人员将有 3 天时间制作，制作完成后发给宣策部负责人庞凌峰（QQ：〔略〕）
- 经审核通过后，将发布在 NIT 计算机公众号上予以推送
- 根据最终文章的阅读量和点赞数评奖

## 评奖

| 奖项   | 奖品             |
| ------ | ---------------- |
| 一等奖 | 小米无线鼠标一个 |
| 二等奖 | 插线板一个       |
| 三等奖 | 签字笔一只       |

## 题材要求

与科技圈、数码圈有关，体现计算机协会的宗旨“帮助电脑小白、普及数码知识”，要求与时事紧密联系。内容不得涉及娱乐圈。
