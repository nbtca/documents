# 协会成员聘书（2016.09—2017.06）

一页聘书的原文：

> 刘 宽 同学：
>
> 兹诚聘您担任浙江大学宁波理工学院计算机协会 会长，任期为 2016 年 9 月至 2017 年 6 月。
>
> 共青团浙江大学宁波理工学院<br>计算机与数据工程学院委员会<br>计算机协会
>
> 2017 年 6 月

同批聘任的还有：

| 姓名   | 职务       |
| ------ | ---------- |
| 刘宽   | 会长       |
| 张登科 | 会长助理   |
| 庞允建 | 副会长     |
| 毛唯丞 | 副会长     |
| 王铭轩 | 副会长     |
| 卫超越 | 软件部部长 |
| 朱柯权 | 硬件部部长 |
| 张哲宇 | 组织部部长 |

这一届分软件部、硬件部、组织部，与同年[协会介绍](/archived/2016/club-introduction)写的一致。落款学院名为“计算机与数据工程学院”。

其中朱柯权次年成了会长，他在[给全体成员的信](/archived/2017/letter-to-all-members)里写“在加入协会一年以后，我选择了担任硬件部的部长”，说的就是这一年。
