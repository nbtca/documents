# CA101

CA101 是 NBTCA 面向所有人的计算机基础讲座。“CA”取自“计算机协会”，“101”表示最基础的一级。本文说明 CA101 这个活动：它是什么，怎样设计一场，讲什么内容。定义和概览见 [CA101 词条](/concepts/ca101)。

## 版权

NBTCA 支持开源。你可以自由阅读、链接、打印、转载和改编本文，但必须保留署名并注明出处。如果你发现错误（包括错别字），请[提交 PR 或来信指正](https://github.com/nbtca/documents)。

## 这是一场什么活动

- **对象**：全校所有人，不要求基础知识。
- **形式和时长**：线下讲座，约两小时，通常在晚上举办，因为多数人晚上有空。
- **场地**：校内能借到的场地，通常是 S 区和 N 区的大教室。
- **发布渠道**：主要通过[社团动态日历](https://nbtca.space/calendar)，也通过其他渠道发布。

## 怎么设计一场 CA101

CA101 是科普讲座。设计时，按下面两条经验：

- **信息密度**：在同样的时间里，视频传递的信息多于图片，图片多于文字。多用直观的方式呈现内容。
- **讲演设计**：听众对讲座的评价，更多取决于他们的感受，而不只取决于讲了什么。设计讲演的过程和节奏。

## 讲什么

CA101 的内容是常见的计算机问题：计算机知识、基础维护和常见的软硬件问题。硬件、系统和维修的具体操作见下面的手册，本文不重复：
