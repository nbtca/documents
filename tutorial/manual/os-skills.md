# 维修常用的 Windows 操作

本文为维修队成员说明维修和排障中最常用的 Windows 操作：文件管理、任务管理器、系统设置、命令行和故障排查。

Windows 的安装见[从零开始安装 Windows](/tutorial/manual/windows-from-scratch)。

## 文件管理

### 文件和文件夹

- Windows 用树状目录组织文件。最顶层是各个磁盘分区（C:、D: 等）。
- 文件名由名称和扩展名组成，例如 `报告.docx`。扩展名决定文件类型和默认的打开程序。
- 常见的扩展名：`.exe`（可执行程序）、`.docx`（Word 文档）、`.pdf`（PDF 文档）、`.zip`（压缩包）。

::: warning 注意
开启文件扩展名显示。Windows 默认隐藏已知文件类型的扩展名。恶意软件常用这一点伪装自己，例如 `照片.jpg.exe` 显示为 `照片.jpg`。
:::

开启扩展名显示：

1. 打开文件资源管理器。
2. 单击“查看”。
3. 勾选“文件扩展名”。

### 常用操作

- **搜索文件**：按 `Win + S` 打开搜索，或者在文件资源管理器的地址栏中输入路径。
- **快捷键**：`Ctrl+C`（复制）、`Ctrl+X`（剪切）、`Ctrl+V`（粘贴）、`Ctrl+Z`（撤销）、`F2`（重命名）、`Shift+Delete`（永久删除，不进入回收站）。
- **查看文件路径**：右键单击文件，选择“属性”，查看完整路径。也可以从地址栏复制路径。
- **分区**：把系统盘（C 盘）和数据盘分开。重装系统时，数据盘中的内容不受影响。

### 用户文件夹

Windows 为每个用户创建一个文件夹 `C:\Users\用户名\`。其中有桌面、文档、下载、图片、音乐和视频等子文件夹。

把桌面和下载文件夹移到非系统盘：

1. 右键单击文件夹，选择“属性”。
2. 选择“位置”选项卡。
3. 单击“移动”，选择目标文件夹。

## 任务管理器

### 打开任务管理器

- 按 `Ctrl + Shift + Esc`。这是最快的方法。
- 按 `Ctrl + Alt + Delete`，在屏幕上选择“任务管理器”。
- 右键单击任务栏，选择“任务管理器”。

### 进程

- 显示所有正在运行的程序和后台进程。
- 单击列标题，按 CPU、内存、磁盘或网络占用排序，找出占用异常的进程。
- 右键单击进程，可以结束任务、打开文件所在的位置或在线搜索。

### 性能

- 实时显示 CPU、内存、磁盘、网络和 GPU 的使用情况和历史曲线。
- CPU 占用长时间为 100% 时，原因可能是程序故障或恶意软件。
- 内存占用过高时，系统变慢。关闭不需要的程序，或者增加内存。

### 启动应用

- 管理开机自动启动的程序。禁用不需要的启动项，开机更快。
- 右键单击启动项，选择“禁用”或“启用”。“启动影响”列显示每一项对开机速度的影响。

::: info 注
电脑运行变慢时，先打开任务管理器，检查资源占用。找出 CPU 或内存占用异常的进程。
:::

## 设置和控制面板

Windows 同时有“设置”应用和传统的“控制面板”。两者的功能有重叠。

### 设置

按 `Win + I` 打开设置。常用的项目：

- **系统**：显示、通知、电源、存储。
- **网络和 Internet**：Wi-Fi、以太网、VPN、代理。
- **个性化**：壁纸、主题、锁屏、任务栏。
- **应用**：已安装的应用、默认应用、启动应用。
- **更新和安全**（Windows 10）或 **Windows 更新**（Windows 11）：系统更新和恢复选项。

### 控制面板

搜索“控制面板”，打开控制面板。控制面板中有一些设置应用中没有的功能：

- **程序和功能**：卸载程序。列表比设置中的应用列表更详细。
- **网络和共享中心**：网络适配器的详细设置和诊断。
- **设备管理器**：查看和管理所有硬件设备和驱动。
- **电源选项**：电源计划的详细设置。

### 设备管理器

设备管理器是排查硬件故障的主要工具。

- **打开**：右键单击“开始”按钮，选择“设备管理器”。也可以按 `Win + X`，再选择“设备管理器”。
- **驱动故障**：设备名称前的黄色感叹号表示驱动有故障。
- **操作**：右键单击设备，可以更新驱动、禁用设备或卸载设备。
- **隐藏设备**：单击“查看 → 显示隐藏的设备”，显示以前连接过、现在没有连接的设备。

## 命令行

命令行用文本命令操作计算机。很多排障操作没有图形界面，只能在命令行中完成。

### 命令提示符（CMD）

- **打开**：搜索“cmd”，或者按 `Win + R` 并输入 `cmd`。
- **以管理员身份运行**：搜索“cmd”，右键单击结果，选择“以管理员身份运行”。

常用命令：

```cmd
:: 查看网络配置
ipconfig /all

:: 清除 DNS 缓存
ipconfig /flushdns

:: 测试网络连通性
ping nbtca.space

:: 跟踪路由
tracert nbtca.space

:: 检查系统文件
sfc /scannow

:: 立即关机
shutdown /s /t 0

:: 立即重启
shutdown /r /t 0
```

### PowerShell

PowerShell 是 Windows 的另一个命令行工具，可以运行大部分 CMD 命令。

- **打开**：搜索“PowerShell”，或者按 `Win + X` 并选择“终端”。
- **命令格式**：PowerShell 的命令称为 cmdlet，例如 `Get-Process` 和 `Get-Service`。

常用命令：

```powershell
# 查看所有进程
Get-Process

# 查看系统信息
Get-ComputerInfo

# 查看已安装的程序
Get-Package

# 查看磁盘空间
Get-PSDrive -PSProvider FileSystem

# 查看网络适配器
Get-NetAdapter

# 查看磁盘信息（Windows 11 已弃用旧的 wmic 命令）
Get-CimInstance Win32_DiskDrive | Select-Object Model, Size, InterfaceType
```

::: info 注
Windows 11 的默认终端是 Windows Terminal。它在多个标签页中运行 PowerShell、CMD 和 WSL。
:::

## 故障排查

### 通用排查步骤

1. 问机主故障的现象、出现的频率和规律。
2. 问机主故障出现前是否安装了新软件、更新了系统或驱动，或者更改了设置。
3. 打开任务管理器，检查 CPU、内存和磁盘的占用。
4. 按 `Win + X`，打开“事件查看器”，展开“Windows 日志”，查看“系统”和“应用程序”日志中的错误。
5. 如果在正常模式下不能操作，进入安全模式排查（见下文）。
6. 在搜索引擎中搜索具体的错误代码或错误信息。

进入安全模式：

- **能进入系统**：打开 `设置 → 系统 → 恢复 → 高级启动`，单击“立即重新启动”，再选择“疑难解答 → 高级选项 → 启动设置”，选择安全模式。在 Windows 10 和 Windows 11 中，开机时按 F8 默认无效。
- **不能进入系统**：在 Windows 启动过程中强制关机，连续两次。Windows 连续两次启动失败后，会自动进入[恢复环境（WinRE）](https://learn.microsoft.com/zh-cn/windows-hardware/manufacture/desktop/windows-recovery-environment--windows-re--technical-reference)。在“疑难解答 → 高级选项 → 启动设置”中选择安全模式。

::: warning 注意
只在不能进入系统时强制关机。强制关机可能使正在写入的文件损坏。
:::

### 常见故障

| 故障               | 可能原因                         | 处理方向                                     |
| ------------------ | -------------------------------- | -------------------------------------------- |
| 开机慢             | 启动项过多、硬盘老化             | 禁用不需要的启动项，检查硬盘健康状态         |
| 系统卡顿           | 内存不足、磁盘占用 100%          | 关闭高占用进程，检查是否有恶意软件           |
| 蓝屏（BSOD）       | 驱动冲突、内存故障、系统文件损坏 | 记下蓝屏代码，查微软文档                     |
| 不能联网           | 驱动缺失、IP 配置错误、DNS 故障  | 检查网卡驱动，重置网络设置                   |
| 软件不能安装或运行 | 缺少运行库、权限不足、兼容性问题 | 安装 VC++ 运行库，用兼容模式运行             |
| 磁盘空间不足       | 临时文件过多、大文件占用         | 见 [C 盘清理](/repair/c-drive-cleanup)       |

### 系统修复工具

Windows 自带下面这些修复工具。所有命令都在以管理员身份运行的 CMD 中执行。

::: warning 注意
如果硬盘可能已经损坏，不要运行 `chkdsk /r`，先备份数据。`/r` 读取整个硬盘，会使损坏的硬盘更快失效。见[故障诊断](/repair/diagnosis)。
:::

::: warning 注意
运行“重置此电脑”前，备份机主的数据。即使选择“保留我的文件”，已安装的程序也会被删除。
:::

- **DISM（部署映像服务和管理）**：运行 `DISM /Online /Cleanup-Image /RestoreHealth`，修复 Windows 组件存储。先运行 DISM，再运行 SFC。
- **SFC（系统文件检查器）**：运行 `sfc /scannow`，检查并修复损坏的系统文件。
- **chkdsk（磁盘检查）**：运行 `chkdsk C: /f /r`，检查并修复磁盘错误。
- **系统还原**：如果以前创建过还原点，把系统恢复到还原点的状态。
- **重置此电脑**：打开 `设置 → 系统 → 恢复 → 重置此电脑`。你可以选择保留或删除个人文件。
