# 从零开始安装 Windows

本文说明怎样在一台空白电脑上安装 Windows：选择版本，获取原版镜像，制作启动 U 盘，安装系统，然后配置网络、驱动和常用软件。

## 选择 Windows 版本

安装前，先确定两件事：

- **Windows 10 或 Windows 11**：如果硬件支持 TPM 2.0 和安全启动，并且 CPU 在 Windows 11 的支持列表中，选择 Windows 11。如果硬件不满足 Windows 11 的要求，选择 Windows 10。
- **家庭版（Home）或专业版（Pro）**：办公和上网用家庭版。如果要使用远程桌面、Hyper-V 或加入域，选择专业版。

::: warning 注意
只从微软官方或可信的镜像站获取原版 ISO 文件，并用 SHA-256 校验。不要使用来源不明的修改版镜像。修改版镜像可能包含恶意软件。
:::

## 获取 Windows

### 方法一：从微软官网下载 ISO 文件

推荐使用这种方法。

1. 打开微软官方下载页面：
   - Windows 10：<https://www.microsoft.com/zh-cn/software-download/windows10>
   - Windows 11：<https://www.microsoft.com/zh-cn/software-download/windows11>
2. 找到“下载 Windows 光盘映像（ISO 文件）”部分。
3. 选择版本。通常选择“Windows 10”或“Windows 11”。这个版本包含家庭版和专业版。
4. 选择语言“简体中文”。
5. 单击“64 位下载”。ISO 文件通常有 4 到 6 GB。

::: info 注
在 Windows 电脑上打开 Windows 10 下载页面时，页面可能只提供媒体创建工具，不显示 ISO 下载链接。要显示 ISO 下载链接：

1. 按 `F12`，打开开发者工具。
2. 把 User Agent 改为 iPad 或 macOS。
3. 刷新页面。
:::

### 方法二：使用媒体创建工具

媒体创建工具（Media Creation Tool）是微软的官方工具。它可以下载镜像，也可以直接制作启动 U 盘。

::: warning 注意
媒体创建工具写入 U 盘时，会清除 U 盘中的所有数据。开始前，备份 U 盘中的数据。
:::

1. 在上面的下载页面中，单击“立即下载工具”（Windows 10 页面）或“下载 Windows 11 安装助手”（Windows 11 页面）。
2. 运行下载的 `MediaCreationTool.exe`。
3. 接受许可条款。
4. 选择“为另一台电脑创建安装介质”。
5. 选择语言、版本和体系结构。体系结构通常选择 64 位。
6. 选择介质：
   - **U 盘**：直接写入 U 盘。U 盘的容量至少为 8 GB。
   - **ISO 文件**：把 ISO 文件下载到本地，以后再写入 U 盘。

### 方法三：使用第三方镜像站

如果访问微软官网的速度太慢，使用下面这些收录微软原版镜像的站点：

- **HelloWindows**：<https://hellowindows.cn/>。提供 SHA-256 校验值。
- **MSDN, I Tell You（ITELLYOU）**：<https://msdn.itellyou.cn/>（旧站）或 <https://next.itellyou.cn/>（新站）。

::: warning 注意
从非微软官方渠道下载镜像后，必须校验 SHA-256 值。只有校验值完全一致时，才能使用这个镜像。
:::

1. 在 PowerShell 中运行下面的命令。把路径换成镜像的实际路径：

   ```powershell
   Get-FileHash "C:\路径\你的镜像.iso" -Algorithm SHA256
   ```

2. 把输出的哈希值与镜像站提供的 SHA-256 值逐字比对。

### 方法四：使用 Visual Studio 订阅

如果你有 Visual Studio 订阅（以前称为 MSDN 订阅），登录 <https://my.visualstudio.com/Downloads>，下载各版本的 Windows 镜像，包括企业版和 LTSC 版。部分高校通过校园协议提供这种订阅，向学校信息中心咨询。

## 制作启动 U 盘

把 ISO 文件写入 U 盘，制作启动 U 盘。

::: warning 注意
写入 ISO 文件会清除 U 盘中的所有数据。开始前，备份 U 盘中的数据。
:::

准备下面两样东西：

- 一个容量至少为 8 GB 的 U 盘。USB 3.0 或更新的 U 盘写入更快。
- 下载好的 Windows ISO 文件。

### 方法一：使用 Rufus

推荐使用这种方法。Rufus 是免费、开源的启动 U 盘制作工具，支持 UEFI 和传统 BIOS 启动。

1. 从 <https://rufus.ie/zh/> 下载 Rufus。便携版不需要安装。
2. 插入 U 盘，运行 Rufus。
3. 在“设备”中，选择你的 U 盘。
4. 在“引导类型选择”中，单击“选择”，选择 Windows ISO 文件。
5. 在“分区类型”中：
   - 如果电脑支持 UEFI 启动（2015 年后的大多数电脑），选择 GPT。
   - 如果电脑只支持传统 BIOS，选择 MBR。
6. 在“目标系统类型”中：
   - 如果分区类型是 GPT，选择 `UEFI (非 CSM)`。
   - 如果分区类型是 MBR，选择 `BIOS (或 UEFI-CSM)`。
7. “文件系统”保持默认值 NTFS。
8. 单击“开始”。写入通常需要 5 到 15 分钟。

::: info 注
制作 Windows 11 启动 U 盘时，Rufus 会显示一个对话框。对话框中有跳过 TPM 2.0 和安全启动检查、跳过微软账户登录等选项。如果电脑不满足 Windows 11 的硬件要求，选择这些选项。
:::

### 方法二：使用 Ventoy

如果一个 U 盘要放多个镜像，使用这种方法。Ventoy 是开源工具。安装 Ventoy 后，把 ISO 文件复制到 U 盘就可以启动。

1. 从 <https://www.ventoy.net/cn/download.html> 下载 Ventoy。
2. 运行 `Ventoy2Disk.exe`。
3. 选择你的 U 盘。
4. 如果 U 盘没有安装过 Ventoy，单击“安装”。如果已经安装过，单击“升级”。
5. 安装完成后，U 盘被分成两个分区。把 Windows ISO 文件复制到较大的分区。
6. 从 U 盘启动时，Ventoy 列出所有 ISO 文件。选择要使用的文件。

::: info 注
一个 Ventoy U 盘可以同时存放 Windows 10、Windows 11 和 PE 系统等多个镜像，不用反复写入。维修队成员可以用一个 U 盘处理多种情况。
:::

### 方法三：使用媒体创建工具

如果你在“获取 Windows”一节中使用了媒体创建工具，在第 6 步选择“U 盘”。不需要其他工具。

### 检查启动 U 盘

1. 在文件资源管理器中打开 U 盘。
2. 确认 U 盘中有 `setup.exe`（Rufus 或媒体创建工具）或 ISO 文件（Ventoy）。
3. 如果分区类型是 GPT，确认 U 盘中有 `EFI` 文件夹。
4. 如果有虚拟机，在虚拟机中测试 U 盘能否启动。

## 安装 Windows

安装分四个阶段：从 U 盘启动，运行安装程序，分区，完成初始设置（OOBE）。

### 第一步：从 U 盘启动

1. 把启动 U 盘插入目标电脑。
2. 开机。厂商标志出现时，连续按启动菜单键。常用的按键有：联想 `F12`，华硕 `Esc`，惠普 `F9`，戴尔 `F12`。所有厂商的按键见[各厂商笔记本 BIOS、Boot Manager 与一键恢复入口](/repair/bios-keys)。
3. 在启动菜单中选择你的 U 盘。U 盘通常显示为 U 盘的品牌名或 `UEFI: USB xxx`。
4. 如果使用 Ventoy，在 Ventoy 菜单中选择 Windows ISO 文件。

如果启动菜单中没有 U 盘：

1. 确认 U 盘已经插好。
2. 进入 BIOS，关闭 Secure Boot（安全启动）。
3. 如果 U 盘的分区类型是 GPT，把启动模式改为 UEFI。
4. 保存设置，重启，再次打开启动菜单。

### 第二步：运行安装程序

1. 从 U 盘启动后，屏幕显示 Windows 安装程序。
2. 选择语言和区域：语言选择 `中文（简体，中国）`，时间和货币格式选择 `中文（简体，中国）`，键盘选择 `微软拼音` 或 `美式键盘`。
3. 单击“现在安装”。
4. 如果有产品密钥，输入密钥。如果没有，单击“我没有产品密钥”。安装完成后再激活。
5. 如果屏幕显示版本列表，按“选择 Windows 版本”一节选择家庭版或专业版。
6. 接受许可条款。
7. 选择“自定义：仅安装 Windows（高级）”。

### 第三步：分区

::: warning 注意
删除分区会清除分区上的所有数据。开始前，确认已经备份重要数据。如果电脑有多块硬盘，确认你选择的是目标硬盘。
:::

**全新安装**（推荐）：

1. 在分区界面，选择目标硬盘上的一个分区，单击“删除”。
2. 对目标硬盘上的每个分区重复第 1 步。
3. 选择“未分配的空间”，单击“新建”。
4. 输入系统分区的大小。系统分区至少为 100 GB，即 102400 MB。Windows 自动创建 EFI 系统分区和 MSR 保留分区等必要分区。
5. 选择刚创建的主分区（通常是最大的分区），单击“下一步”。

**保留数据分区的安装**：

如果要保留 D 盘等数据分区，只删除原来的系统分区（通常是 C 盘和相关的 EFI 分区、恢复分区）。在得到的未分配空间上新建分区，再安装。

安装程序复制文件、安装功能和更新，通常需要 10 到 30 分钟。在这期间，电脑会自动重启几次。

::: warning 注意
电脑第一次重启时，拔下 U 盘。如果不拔下，电脑可能再次从 U 盘启动安装程序。
:::

### 第四步：初始设置（OOBE）

安装完成后，屏幕显示初始设置（OOBE）界面。

1. 选择地区 `中国`。
2. 选择键盘布局 `微软拼音`。跳过第二键盘布局。
3. 在联网界面：
   - Windows 11 默认要求联网，并用微软账户登录。
   - 如果要使用本地账户，按下文“跳过 Windows 11 的联网和微软账户要求”操作。
4. 设置用户名和密码。
5. 在隐私设置中，关闭所有选项（位置、诊断数据、广告 ID 等）。
6. 等待系统完成配置，进入桌面。

### 跳过 Windows 11 的联网和微软账户要求

Windows 11 安装时默认要求联网，并用微软账户登录。要创建本地账户，使用下面的一种方法。

#### 方法一：用命令跳过

::: info 注
较新的 Windows 11 镜像已经开始移除 `bypassnro` 命令。如果系统提示命令不存在，使用方法二，或查找当前版本可用的其他方法。
:::

1. 在 OOBE 的联网界面，按 `Shift + F10`，打开命令提示符。
2. 输入下面的命令，按 Enter：

   ```cmd
   oobe\bypassnro
   ```

3. 电脑自动重启，再次进入 OOBE。
4. 在联网界面，单击“我没有 Internet 连接”。

#### 方法二：用 Rufus 跳过

用 Rufus 制作启动 U 盘时，选择“移除 Windows 11 对在线微软帐户的要求”。安装时自动跳过联网要求。

::: info 注
本地账户可以满足个人使用的需要。微软账户可以同步设置和 OneDrive，但会上传更多使用数据。
:::

## 配置网络

新安装的 Windows 常常没有网卡驱动，台式机和部分笔记本更常见。安装驱动要联网，联网又要驱动。先解决联网问题。

### 检查网络状态

进入桌面后，检查任务栏右下角的网络图标：

- **显示 Wi-Fi 图标**：无线网卡驱动已经安装。连接 Wi-Fi。
- **显示有线连接图标**：插入网线。
- **显示红叉或没有网络图标**：网卡驱动缺失。用下面的一种方法安装。

### 网卡驱动缺失时

下面这些情况常常没有网卡驱动：

- Intel 较新的 Wi-Fi 网卡（例如 AX201、AX211、BE200）；
- 使用 Realtek 2.5G 有线网卡的台式机；
- 版本较老的 Windows，不包含新硬件的驱动。

#### 方法一：用手机的 USB 网络共享

这种方法最简单。

1. 用数据线把手机连接到电脑。
2. 在手机上开启 USB 网络共享：
   - Android：`设置` → `更多连接方式` → `USB 网络共享`。不同品牌的路径不同。
   - iPhone：`设置` → `个人热点`。用数据线连接后自动共享。
3. 电脑自动识别手机网络并联网，不需要其他驱动。

#### 方法二：提前准备网卡驱动

在另一台能上网的电脑上下载网卡驱动，复制到 U 盘：

1. 查看目标电脑的网卡型号。在设备管理器中查看，或者在电脑厂商官网查看规格参数。
2. 从网卡厂商官网下载驱动：
   - Intel 无线网卡：<https://www.intel.cn/content/www/cn/zh/download-center/home.html>
   - Realtek 网卡：<https://www.realtek.com/Download>
3. 把驱动文件复制到 U 盘。
4. 在目标电脑上安装驱动。

#### 方法三：使用离线网卡驱动工具

提前把“驱动总裁（离线网卡版）”或“360 驱动大师网卡版”等工具下载到 U 盘。这些工具包含常见的网卡驱动，可以不联网安装网卡驱动。

::: info 注
维修队成员的 U 盘中应常备一份离线网卡驱动包，用于各种机型。
:::

### 连接校园网

大部分高校的[校园网](/concepts/campus-network-auth)要通过网页认证或专用客户端登录。

- **有线连接**：
  1. 插入网线。
  2. 在浏览器中打开任意网页。浏览器通常自动转到校园网认证页面。
  3. 输入学号和密码，登录。
- **无线连接**：
  1. 连接校园 Wi-Fi（例如 `NBUT-WiFi`）。
  2. 在浏览器中完成认证。
- **专用客户端**：按学校网络中心的说明下载并安装客户端。

## 安装驱动和基础组件

联网后，先安装所有硬件驱动，再安装系统运行所需的基础组件。

### 安装硬件驱动

#### 方法一：从电脑厂商官网下载

推荐使用这种方法。它最安全，也最可靠。在电脑厂商的官方支持页面输入机型或序列号，下载对应的驱动。

| 厂商 | 驱动下载页面                                  |
| ---- | --------------------------------------------- |
| 联想 | <https://support.lenovo.com/>                 |
| 华硕 | <https://www.asus.com.cn/support/>            |
| 惠普 | <https://support.hp.com/cn-zh/drivers>        |
| 戴尔 | <https://www.dell.com/support/home/zh-cn>     |
| 宏碁 | <https://www.acer.com.cn/support.html?type=1> |
| 华为 | <https://consumer.huawei.com/cn/support/>     |
| 小米 | <https://www.mi.com/service/bijiben>          |

按下面的顺序安装驱动：

1. **芯片组驱动**（Chipset）：主板芯片组的基础驱动，影响系统的稳定性。
2. **显卡驱动**（Graphics）：
   - Intel 或 AMD 集成显卡：从 Intel 或 AMD 官网下载。
   - NVIDIA 独立显卡：<https://www.nvidia.cn/Download/index.aspx>
   - AMD 独立显卡：<https://www.amd.com/zh-cn/support/download/drivers.html>
3. **声卡驱动**（Audio）：通常是 Realtek 驱动。从电脑厂商官网下载。
4. **触控板驱动**（Touchpad）：笔记本需要安装。没有这个驱动，触控板手势不能使用。
5. **蓝牙驱动**（Bluetooth）：连接蓝牙耳机和鼠标时需要。
6. **其他驱动**：指纹识别、摄像头、读卡器等。按需要安装。

#### 方法二：使用 Windows 更新

Windows 更新会检测并安装大部分常见硬件的驱动。

1. 打开 `设置` → `Windows 更新`。
2. 单击“检查更新”，等待系统下载并安装驱动。
3. 打开“可选更新”，选择其中的驱动并安装。

::: info 注
Windows 更新提供的显卡驱动通常不是最新版本。要玩游戏，从 NVIDIA 或 AMD 官网下载最新的驱动。
:::

#### 方法三：使用驱动管理工具

如果不知道硬件型号，用下面的工具检测并安装驱动：

- **Snappy Driver Installer Origin（SDIO）**：开源、免费、没有广告，支持离线驱动包。下载地址：<https://www.snappy-driver-installer.org/>
- **驱动总裁**：包含大量驱动，用于批量装机。

::: warning 注意
不要使用“驱动人生”“驱动精灵”等工具的在线版本。这些版本通常捆绑安装其他软件。如果必须使用，选择离线版或网卡版，并在安装完驱动后立即卸载这个工具。
:::

### 安装运行库和基础组件

很多软件和游戏需要下面的运行库。全部安装。

#### Visual C++ 运行库

很多软件和游戏需要微软的 Visual C++ 运行库。用 Visual C++ Redistributable AIO（All in One）一次安装所有版本：

- GitHub 下载：<https://github.com/abbodi1406/vcredist>

也可以从微软官网下载最新版本：<https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist>

#### .NET Framework 和 .NET 运行时

部分软件需要 .NET 运行时。

- .NET Framework 3.5：打开 `设置` → `应用` → `可选功能` → `更多 Windows 功能`，勾选 .NET Framework 3.5。
- .NET 8 或 .NET 9 运行时：<https://dotnet.microsoft.com/zh-cn/download>

#### DirectX

游戏需要 DirectX。Windows 自带的 DirectX 通常可以满足需要。部分老游戏还需要 DirectX End-User Runtime：

- 下载地址：<https://www.microsoft.com/zh-cn/download/details.aspx?id=35>

#### 7-Zip

Windows 自带的解压功能支持的格式较少。安装 7-Zip：

- 下载地址：<https://7-zip.org/>

7-Zip 免费、开源，支持 `.7z`、`.rar`、`.tar`、`.gz` 等大多数压缩格式。

### 安装软件

::: warning 注意
只从软件官网下载。不要点搜索结果中标为“广告”的链接。这些链接通常指向捆绑了其他软件的下载站。
:::

1. 打开软件官网，下载安装程序。
2. 运行安装程序，阅读每一步的内容。
3. 取消勾选“安装 XXX 浏览器”“设 XXX 为主页”等捆绑选项。
4. 把安装路径改到系统盘以外的分区（例如 `D:\Software\`），以减少 C 盘的占用。

不要安装 360、腾讯电脑管家、2345 等安全软件。Windows 自带的 Microsoft Defender 可以满足需要。

## 个性化配置

系统、驱动和软件安装完成后，按个人习惯调整设置。

### 任务栏和开始菜单

#### Windows 11

- **任务栏对齐方式**：打开 `设置` → `个性化` → `任务栏` → `任务栏行为`，把“任务栏对齐方式”改为“靠左”。
- **隐藏图标**：在 `任务栏项` 中，关闭“小组件”“任务视图”“聊天”等按钮。
- **显示秒数**：在 `任务栏行为` 中，勾选“在系统托盘时钟中显示秒”。

#### Windows 10

- **隐藏搜索框**：右键单击任务栏，选择 `搜索` → “隐藏”或“显示搜索图标”。
- **隐藏 Cortana**：右键单击任务栏，取消勾选“显示 Cortana 按钮”。
- **小任务栏按钮**：打开 `设置` → `个性化` → `任务栏`，开启“使用小任务栏按钮”。

### 关闭数据收集

Windows 默认收集大量使用数据。按下面的步骤关闭：

1. 打开 `设置` → `隐私与安全性`（Windows 11）或 `设置` → `隐私`（Windows 10）。
2. 在“常规”中，关闭“允许应用使用广告 ID”“允许网站通过访问我的语言列表来提供本地相关内容”等所有选项。
3. 在“诊断和反馈”中，把诊断数据设为“必需”，关闭“改进墨迹书写和键入”和“量身定制的体验”。
4. 在“活动历史记录”中，取消勾选“在此设备上存储我的活动历史记录”。

专业版和企业版还可以用组策略设置：

1. 按 `Win + R`，输入 `gpedit.msc`，按 Enter。
2. 打开 `计算机配置` → `管理模板` → `Windows 组件` → `数据收集和预览版本`。
3. 把诊断数据设为最低级别。

### 电源计划

**笔记本**：

1. 打开 `设置` → `系统` → `电源和电池`（Windows 11）或 `电源和睡眠`（Windows 10）。
2. 插电时：把电源模式设为“最佳性能”。屏幕关闭时间设为 10 到 15 分钟。
3. 使用电池时：把电源模式设为“平衡”或“最佳能效”。屏幕关闭时间设为 5 分钟。

**台式机**：

1. 打开 `控制面板` → `硬件和声音` → `电源选项`。
2. 选择“高性能”电源计划。
3. 如果没有“高性能”选项，在 PowerShell 中运行下面的命令，启用它：

   ```powershell
   powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c
   ```

专业版和企业版可以使用“卓越性能”电源计划：

1. 在 PowerShell 中运行：

   ```powershell
   powercfg /duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
   ```

2. 在电源选项中选择“卓越性能”。

### Windows 更新

Windows 更新默认在后台下载和安装更新，有时会在不合适的时间重启电脑。

::: warning 注意
不要完全关闭 Windows 更新。安全更新修复系统漏洞。关闭更新会使电脑更容易受到恶意软件攻击。只调整更新的时间。
:::

- **活动时间**：打开 `设置` → `Windows 更新` → `高级选项` → `活动时间`，设置你常用电脑的时间段。Windows 不会在这个时间段内自动重启。
- **暂停更新**：如果近期有重要的工作或考试，暂停更新。最多可以暂停 5 周。
- **只安装安全更新**：在 `高级选项` 中，关闭“接收其他 Microsoft 产品的更新”和“获取最新更新”。

### 文件资源管理器

1. 打开文件资源管理器，单击 `查看`（Windows 10 在功能区中；Windows 11 单击顶部的 `...`）→ `选项`，打开“文件夹选项”。
2. 在“常规”选项卡中，把“打开文件资源管理器时打开”改为“此电脑”。默认值是“快速访问”。
3. 在“查看”选项卡中：
   - 取消勾选“隐藏已知文件类型的扩展名”。显示扩展名（例如 `.exe`、`.docx`）可以帮助你识别伪装成文档的病毒。
   - 选择“显示隐藏的文件、文件夹和驱动器”。

### 默认应用

1. 打开 `设置` → `应用` → `默认应用`。
2. 把浏览器设为你安装的浏览器，例如 Chrome 或 Firefox。
3. 把视频播放器设为 PotPlayer 或你安装的其他播放器。
4. 把 PDF 阅读器设为你使用的工具。Edge 也可以打开 PDF。

### 输入法

Windows 自带微软拼音输入法。如果要使用第三方输入法：

- **小狼毫（Rime）**：开源输入法，可以深度定制，没有广告。下载地址：<https://rime.im/>
- **搜狗、百度等输入法**：在设置中关闭“广告推送”和“热点推荐”。关闭云联想，以免上传你输入的内容。

微软拼音的快捷键：

- `Ctrl + Shift + B`：打开 Emoji 面板。
- `Win + .`（句号）：打开表情符号面板。
- `Ctrl + Shift + F`：切换简体和繁体。
