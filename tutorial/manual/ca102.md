# CA102

CA102 是 NBTCA 的进阶计算机技能讲座，是 [CA101](./ca101) 的延伸，面向已有计算机基础知识的成员。定义和概览见 [CA102 词条](/concepts/ca102)。

## 版权

与 CA101 相同：你可以自由阅读、链接、打印、转载和改编本文，但必须保留署名并注明出处。如果你发现错误，请[提交 PR 或来信指正](https://github.com/nbtca/documents)。

## 特征

- **目的**：为协会成员提供进阶的计算机技能培训。
- **时长**：2 到 3 小时，通常在周末或课余时间。
- **地点**：线下，通常在协会活动室或社团教室。
- **对象**：参加过 CA101 或有同等基础的协会成员。
- **形式**：讲座加实际操作。

## 涵盖内容

CA102 以 CA101 为基础，包括下面几个模块：

### 网络进阶

在 CA101 的网络基础上深入讲解：

- **网络分层模型**：OSI 七层模型和 TCP/IP 四层模型的实际意义，常见协议工作在哪一层。
- **子网和路由**：IP 地址分类、子网掩码计算、路由的基本概念。
- **抓包和分析**：用 Wireshark 等工具捕获和分析网络数据包，排查网络问题。
- **常用网络服务**：HTTP 和 HTTPS 的工作过程、SSH 远程连接、FTP 文件传输。
- **校园网**：校园网的认证机制，常见问题的排查和处理。

通过实际操作学习网络知识：用 `ping`、`tracert` 和 `nslookup` 排查真实的网络问题，用 Wireshark 抓包，观察一个 HTTP 请求的完整过程。

### 系统管理

操作系统的管理技能：

- **用户和权限**：Windows 的账户类型、管理员权限、UAC 机制。
- **服务**：Windows 服务的概念，用 `services.msc` 管理服务。
- **注册表**：Windows 注册表的结构和作用，常见的注册表修改。
- **组策略**：在 Windows 专业版和更高版本中，用 `gpedit.msc` 配置系统策略。
- **虚拟化**：用 Hyper-V 或 VirtualBox 创建虚拟机，搭建测试环境。

::: warning 注意
修改注册表前，先备份注册表或创建还原点。错误的注册表修改会使系统不能启动。
:::

### 安全基础

安全意识和基本的安全技能：

- **恶意软件分类**：病毒、木马、蠕虫、勒索软件和间谍软件的区别和特征。
- **系统加固**：关闭不需要的服务和端口，启用防火墙，配置 Microsoft Defender。
- **数据加密**：BitLocker 磁盘加密和文件加密的概念和操作。
- **安全工具**：用 Autoruns 检查启动项，用 Process Explorer 分析进程，使用火绒等杀毒软件。

::: warning 注意
只在你自己的设备上或已获得授权的环境中做渗透测试和安全实验。在其他系统上做这些操作是违法的。
:::

### 开发入门

为想参与协会项目开发的成员提供入门指导：

- **开发环境**：安装 VS Code、Git、Node.js 或 Python 等开发工具。
- **版本控制**：Git 的基本概念和常用命令（`clone`、`add`、`commit`、`push`、`pull`）。
- **GitHub 协作**：Issue、Pull Request 和 Code Review 的工作流程。
- **Web 基础**：HTML、CSS 和 JavaScript 的基本概念，网页的工作原理。
- **协会项目**：NBTCA 在 [GitHub](https://github.com/nbtca) 上的开源项目，以及怎样提交贡献。

没有编程基础时，按这个顺序学习：Git 基础 → HTML 和 CSS → JavaScript → 参与协会项目。在实际项目中学习编程最有效。

## 与 CA101 的关系

| 对比项   | CA101                | CA102                    |
| -------- | -------------------- | ------------------------ |
| 定位     | 面向最广泛人群的科普 | 面向协会成员的进阶培训   |
| 前置要求 | 无                   | 具备 CA101 同等基础      |
| 内容深度 | 概念认知为主         | 实操技能为主             |
| 硬件内容 | 了解硬件组成和功能   | 能够评估、组装和排障     |
| 软件内容 | 了解系统和软件分类   | 能够管理系统和排查问题   |
| 网络内容 | 了解基本网络概念     | 能够配置网络和排查故障   |
| 编程内容 | 了解编程是什么       | 能够搭建环境和写基础代码 |

## 后续学习

完成 CA102 后，按自己的兴趣选择方向：

- **维修**：加入维修部，参与实际维修。见[维修操作指南](../../repair/guide)。
- **开发**：加入开发部（从 [dev101](https://github.com/nbtca/dev101) 开始），参与[协会项目](/about/infrastructure)的开发，学习前端、后端或运维。
- **网络和安全**：学习网络协议、渗透测试和安全防护。
- **硬件**：学习硬件选型、组装、超频和服务器搭建。
