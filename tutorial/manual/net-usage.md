# 上网、搜索与网络排障

本文为维修队成员和新成员说明上网的常用方法和常见网络故障的排查：浏览器、搜索、网络故障、VPN 和代理，以及网络安全。

## 浏览器

### 浏览器的选择

- **Google Chrome**：市场份额最高，扩展多，开发者工具完善，内存占用较高。
- **Mozilla Firefox**：开源，注重隐私，可以深度定制。
- **Microsoft Edge**：Windows 自带，基于 Chromium，与 Windows 集成。
- 不要使用 360 浏览器、QQ 浏览器等国产“套壳”浏览器。它们通常捆绑广告和推送。

### 快捷键

- `Ctrl + T`：新建标签页。
- `Ctrl + W`：关闭当前标签页。
- `Ctrl + Shift + T`：恢复刚关闭的标签页。
- `Ctrl + L`：选中地址栏，输入网址或搜索内容。
- `Ctrl + F`：在页面中搜索。
- `F12`：打开开发者工具，查看网页源代码和网络请求。

### 安全设置

- 把浏览器更新到最新版本。
- 不要安装来源不明的扩展。
- 安装 uBlock Origin，拦截广告。
- 定期清除浏览器缓存和 Cookie。

::: warning 注意
不要在公共电脑上保存密码和登录状态。使用后，清除浏览数据，或者一开始就使用隐私模式。
:::

## 搜索引擎

### 搜索引擎的选择

- **Google**：索引最全，英文搜索结果的质量最高。
- **Bing**：微软的搜索引擎，在国内可以直接访问。
- **百度**：中文市场份额最高。搜索结果中广告较多，注意区分。

### 搜索语法

- **精确搜索**：用双引号。`"蓝屏代码 0x0000007E"` 只匹配这个完整的短语。
- **排除关键词**：用减号。`Python 教程 -广告 -培训` 排除包含“广告”和“培训”的结果。
- **站内搜索**：用 `site:`。`site:github.com NBTCA` 只在 GitHub 中搜索。
- **文件类型**：用 `filetype:`。`filetype:pdf 操作系统原理` 只搜索 PDF 文件。
- **英文搜索**：技术问题用英文关键词在 Google 上搜索，通常能找到更专业的答案。

::: info 注
遇到技术问题时，直接搜索错误信息（特别是英文错误代码），通常比描述现象更快找到答案。Stack Overflow、GitHub Issues 和技术论坛是常见的答案来源。
:::

## 网络故障排查

### 排查步骤

按下面的顺序排查：

1. 检查物理连接：网线已插好，Wi-Fi 已打开，飞行模式已关闭。
2. 打开设备管理器，确认网卡前没有黄色感叹号。
3. 运行 `ipconfig`，确认电脑得到了正确的 IP 地址。
4. 运行 `ping 127.0.0.1`，测试本机网络协议栈。
5. 运行 `ping` 加网关地址，测试局域网。
6. 运行 `ping 8.8.8.8`，测试外网。
7. 运行 `ping baidu.com`，测试 DNS。
8. 如果以上测试有失败，以管理员身份运行 `netsh winsock reset` 和 `ipconfig /flushdns`，再重启电脑。

### 常见网络故障

| 现象                   | 可能原因                     | 处理方法                                |
| ---------------------- | ---------------------------- | --------------------------------------- |
| 完全不能联网           | 网卡驱动缺失、硬件故障       | 检查设备管理器，重新安装网卡驱动        |
| 能连接 Wi-Fi 但不能上网 | DNS 配置错误、IP 冲突        | 手动设置 DNS，释放并重新获取 IP         |
| 网页打不开但 QQ 能用   | DNS 解析失败                 | 更换 DNS 服务器（223.5.5.5 或 8.8.8.8） |
| 网速很慢               | 带宽被占用、信号差           | 检查后台下载，靠近路由器                |
| 校园网不能认证         | 认证客户端故障、MAC 地址绑定 | 重新安装认证客户端，检查设备注册        |

### 校园网

- [校园网](/concepts/campus-network-auth)通常要通过网页认证或专用客户端认证后才能上网。
- 校园网账号限制同时在线的设备数量。超出限制时，先让其他设备下线。
- 校园网通常限制 P2P 下载。遵守学校的网络规定。

## VPN 和代理

### 概念

- **VPN（虚拟专用网络）**：在公共网络上建立加密隧道，保护通信数据。企业用 VPN 使远程员工安全访问公司内网。
- **代理服务器**：客户端和目标服务器之间的中转。代理服务器代替客户端发送请求，再把响应转发给客户端。
- **正向代理**：客户端通过代理访问外部资源，例如访问国际学术资源。
- **反向代理**：服务器端用代理接收和分发请求，例如 [Nginx](/tutorial/manual/nginx-usage) 反向代理。

### 访问学术资源

- 许多国际学术数据库要通过学校图书馆的 VPN 或代理访问。
- 学校通常提供 WebVPN 或 VPN 客户端，用于在校外访问校内资源。
- 获取学术文献的渠道包括 Google Scholar、Sci-Hub 和学校图书馆的数据库。

组网和远程访问的方法见 [Tailscale 使用指南](/tutorial/manual/tailscale-usage)。

## 网络安全和隐私

### 密码

- 使用强密码：至少 12 位，包含大写字母、小写字母、数字和特殊字符。
- 在不同的网站使用不同的密码。
- 用密码管理器（例如 Bitwarden 或 KeePass）管理密码。
- 在支持两步验证（2FA）的网站上开启两步验证。

### 常见威胁

- **钓鱼攻击**：检查邮件的发件人地址和链接的网址。不要点击可疑链接。不要在陌生网站上输入个人信息。
- **恶意软件**：不要下载来源不明的软件。保持系统和杀毒软件为最新版本。
- **社会工程**：不要向陌生人提供个人信息或账号密码，即使对方自称是官方客服。
- **公共 Wi-Fi**：不要在公共 Wi-Fi 上使用网银或支付。如果必须使用，先连接 VPN。

::: warning 注意
不要轻信陌生人，不要转账，不要泄露个人信息。电信诈骗的形式很多。遇到疑似诈骗时，立即报告学校保卫处和公安机关。
:::

### 个人隐私

- 检查应用请求的权限。不要授予不必要的权限，例如天气应用请求通讯录权限。
- 定期检查社交媒体上公开的个人信息，删除不需要公开的内容。
- 浏览不想留下记录的内容时，使用隐私模式。
- 使用公共设备后，退出所有登录，并清除浏览数据。
- 了解各平台的隐私设置，并按需要设置。
