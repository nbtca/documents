# 选配并组装一台电脑

本文说明怎样从零开始组装一台台式电脑：确定需求，选择配件，了解各部件的作用，购买和评估二手配件，组装，以及组装后的测试和日常维护。

## 确定需求

你可以自己选择每个配件，也可以购买整机。无论用哪种方式，都要先确定这台电脑的用途。例如，它用于运行对图形性能要求高的大型游戏，或者用作长期运行的低功耗服务器。用途决定硬件的性能要求。用途和预算一起决定最终的采购清单。

### 常见用途和参考配置

下表列出几种常见用途和对应的配置方向。下表只作参考。按购买时的市场价格和实际预算调整配置。

| 用途               | CPU                                  | 内存             | 显卡               | 存储            | 参考预算     |
| ------------------ | ------------------------------------ | ---------------- | ------------------ | --------------- | ------------ |
| 办公、上网、影音   | 入门级（如 Intel i3 / AMD R5）       | 8-16GB DDR5      | 集成显卡           | 512GB SSD       | 2000-3000 元 |
| 编程开发           | 中端（如 Intel i5 / AMD R5）         | 16-32GB DDR5     | 集成显卡或入门独显 | 512GB-1TB SSD   | 3000-5000 元 |
| 游戏（中高画质）   | 中高端（如 Intel i5/i7 / AMD R5/R7） | 16-32GB DDR5     | 中高端独显         | 1TB SSD         | 5000-8000 元 |
| 视频剪辑、3D 渲染  | 高端（如 Intel i7/i9 / AMD R7/R9）   | 32-64GB DDR5     | 高端独显           | 1TB+ SSD + HDD  | 8000 元以上  |
| 家用轻量服务器、NAS | 低功耗 CPU                          | 8-16GB ECC/非ECC | 集成显卡           | 大容量 HDD 为主 | 按需求确定   |

::: info 注
上表的预算只包括主机，不包括显示器和外设。硬件价格变化大。购买前，查看最新的评测和价格。
:::

### 评估硬件参数

#### CPU

- **核心数和线程数**：多核心有利于多任务和编译。游戏更依赖单核性能。
- **基础频率和最大加速频率**。
- **功耗（TDP）**：决定需要什么样的散热器。
- **插槽**：CPU 必须与主板插槽一致，例如 LGA 1700 或 AM5。

#### 内存

- **容量**：至少 16GB。开发和创作用 32GB。
- **频率和时序**：频率越高、时序越低，性能越好。主板和 CPU 必须支持所选的频率。
- **通道数**：双通道（两根内存条）的性能明显高于单通道。

#### 显卡

- **显存容量**：游戏用 8GB 以上。AI 和渲染用 12GB 以上。
- **性能天梯图**：硬件媒体发布的显卡性能排名，用于比较。
- **功耗和尺寸**：电源功率必须足够，机箱必须能装下显卡。

#### 存储

- **接口和协议**：NVMe（M.2 接口）比 SATA 快得多。
- **读写速度**：随机读写速度比顺序读写速度更影响实际使用。
- **寿命（TBW）**：可以写入的数据总量。正常使用时，寿命通常不是问题。

#### 电源

- **额定功率**：在所有硬件的总功耗上，再留 30% 到 50% 的余量。
- **转换效率认证**：选择 80 Plus 铜牌或更高等级。
- **品牌和质量**：电源损坏会损坏其他所有硬件。不要为了省钱买质量差的电源。

## 硬件组成

一台计算机由下面这些部件组成：

- **中央处理器（CPU）**：处理数据。
- **内存**：临时存放正在运行的程序和数据。断电后，内存中的数据消失。
- **硬盘**：长期存储数据。
- **电源**：为各部件供电。
- **独立显卡**：处理 CPU 不擅长的图形计算。如果不需要大量图形计算，选择带集成显卡的 CPU，不买独立显卡。
- **主板**：连接所有部件。
- **散热器**：为 CPU 等发热部件散热。散热器分为风冷和水冷两种。
- **机箱**：安装和保护各部件，并影响散热气流。

## 购买

购买整机时，检查三件事：价格是否合理，性能是否满足需要，售后服务是否完善。

评测结果和购买渠道都很多。多看、多比较。预算不够时，可以考虑二手硬件，但要更仔细地评估。

### 购买渠道

- **线上自营平台**：例如京东自营和天猫旗舰店。商品是正品，售后方便。
- **线下实体店**：可以实际看到硬件。注意加价和调换配件。
- **二手平台**：例如闲鱼和转转。价格低，但你要能鉴别硬件的状况。
- **海外渠道**：部分硬件价格更低，但要考虑保修和关税。

### 评估二手硬件

::: warning 注意
购买二手硬件时，必须当面或通过视频验货，确认硬件功能正常。
:::

- **CPU**：故障率很低。检查针脚或触点是否完好。
- **内存**：检查颗粒品牌和频率是否与标注一致。运行 MemTest，检查稳定性。
- **显卡**：风险最高的二手硬件，市场上有很多挖矿用过的显卡。检查外观磨损、风扇噪声和满载温度。
- **硬盘**：用 CrystalDiskInfo 检查通电时间和健康状态。不要购买通电时间很长的硬盘。
- **电源**：不要购买二手电源。老化的电源可能损坏其他硬件。

## 组装

接口和协议、供电和机箱空间都会限制组装方法，每一代硬件也不同。组装前，阅读各部件的安装手册，并参考同一代硬件的装机经验。

::: danger 警告
组装前，关闭电源开关，拔下电源线。在组装完成并检查所有连接之前，不要接通电源。通电时安装部件会造成触电和短路。
:::

::: warning 注意
接触部件前，触摸接地的金属物体，或戴上防静电手环。静电会损坏 CPU、内存和主板。
:::

### 组装顺序

按下面的顺序组装台式机。

#### 安装 CPU

::: warning 注意
不要触碰 CPU 和插槽上的针脚或触点。针脚弯曲会使 CPU 或主板不能使用。
:::

1. 打开主板 CPU 插槽的压杆。
2. 把 CPU 上的防呆缺口对准插槽，把 CPU 轻轻放入插槽。
3. 扣好压杆。

#### 安装内存条

1. 把内存条上的缺口对准插槽。
2. 用力均匀地按下内存条，直到两侧卡扣自动锁定。卡扣没有锁定时，电脑不能开机。
3. 如果用两根内存条组成双通道，按主板说明书隔一个插槽安装。

#### 安装 M.2 固态硬盘

1. 把固态硬盘斜着插入 M.2 插槽。
2. 把固态硬盘压平，装上固定螺丝。

#### 安装 CPU 散热器

::: warning 注意
安装散热器前，撕掉散热器底部的保护膜。保护膜会使散热很差，CPU 会很快过热。
:::

1. 在 CPU 中央涂一粒米大小的硅脂。硅脂太多会溢出到主板上。
2. 把散热器放在 CPU 上。
3. 按对角线顺序拧紧散热器螺丝。不要拧得过紧，过紧会使主板变形。

#### 把主板装入机箱

::: warning 注意
在装入主板之前，先把 I/O 挡板装到机箱上。如果先装入主板，你必须拆下主板才能装挡板。
:::

1. 把 I/O 挡板装到机箱上。
2. 把主板的螺丝孔对准机箱的铜柱。
3. 拧紧主板的固定螺丝。不要拧得过紧。

#### 安装电源

1. 按机箱的结构，把电源装到电源位上。
2. 拧紧电源的固定螺丝。

#### 安装显卡

1. 把显卡插入 PCIe 插槽，直到插槽末端的卡扣锁定。
2. 拧紧显卡挡板的螺丝。
3. 接上显卡的供电线。

#### 连接线缆

1. 连接主板的 24pin 主供电线。
2. 连接 CPU 的 8pin 辅助供电线。没有这根线，电脑不能开机。
3. 连接 SATA 数据线和 SATA 电源线（如果有 SATA 设备）。
4. 连接前面板线：开机键、重启键、指示灯、USB 和音频。开机键和重启键不分正负极。LED 指示灯分正负极。

#### 整理线缆

1. 整理线缆，使线缆不挡住风道。

## 组装后的测试

组装完成后，先做基本检查，再安装操作系统。

### 第一次开机检查

1. 接通电源，按下开机键。
2. 检查 CPU 风扇、机箱风扇和显卡风扇是否转动。
3. 如果不能进入 BIOS，查看主板上的 Debug 灯或听蜂鸣声。它们表示故障部件：CPU、内存、显卡或存储。
4. 进入 BIOS，确认 CPU 型号、内存容量、内存频率和存储设备都被正确识别。
5. 在 BIOS 中开启 XMP（Intel）或 EXPO（AMD），使内存以标称频率运行。

### 稳定性测试

安装[操作系统](/tutorial/manual/windows-from-scratch)后，运行下面的测试。大部分工具可以在[软件仓库索引](/repair/tools)中找到。

- **CPU**：用 AIDA64 或 Prime95 运行压力测试 15 到 30 分钟，检查温度和是否报错。
- **内存**：用 MemTest86 或 Windows 内存诊断检查内存错误。
- **显卡**：用 FurMark 或 3DMark 运行压力测试。
- **硬盘**：用 CrystalDiskMark 测试读写速度是否达到标称值。
- **整机**：运行大型游戏或渲染任务 1 到 2 小时，检查是否出现蓝屏、死机或其他异常。

正常的温度范围：

- CPU 满载温度不超过 90°C。日常使用时低于 60°C。
- GPU 满载温度在 70°C 到 85°C 之间。

如果温度过高，检查散热器是否装好、硅脂是否涂好、机箱风道是否通畅。

### 常见开机故障

| 现象                     | 可能原因                                 | 排查方法                                           |
| ------------------------ | ---------------------------------------- | -------------------------------------------------- |
| 按开机键没有反应         | 电源没有通电、前面板线没有接、电源损坏   | 检查电源开关和线缆，短接主板的开机针脚             |
| 风扇转但没有画面         | 内存没有插好、显卡没有插好、显示器线接错 | 重新插拔内存和显卡，确认显示器接在显卡上而不是主板上 |
| 反复重启                 | CPU 供电没有接、散热器没有装好导致过热保护 | 检查 CPU 8pin 供电线和散热器                       |
| 能进入 BIOS 但找不到硬盘 | SATA 或 M.2 没有接好、BIOS 中没有启用接口 | 重新插拔存储设备，检查 BIOS 设置                   |
| 蓝屏或频繁死机           | 内存不兼容或损坏、驱动有问题             | 运行内存测试，一次只装一根内存条逐一排查           |

## 日常维护

- **清灰**：每 6 到 12 个月清理一次机箱内部的灰尘，重点清理散热器和风扇。
- **更换硅脂**：每 1 到 2 年更换一次 CPU 硅脂。
- **检查温度**：用 HWMonitor 或 AIDA64 定期检查硬件温度。
- **更新固件**：固态硬盘固件或主板 BIOS 有重要更新时升级。不要频繁升级。
- **防雷**：使用带浪涌保护的插座。雷雨天拔下电源插头。
