# 软件仓库（校内镜像站）

软件仓库是 NBTCA 的校内镜像服务器（[i.nbtca.space](https://i.nbtca.space/)）。它为校内人员提供常用的软件、文件和操作系统镜像。软件仓库只能在校园网内网访问。

下面的链接大多指向内网地址。访问前，先完成[校园网认证](/concepts/campus-network-auth)。不购买校园网套餐也可以访问。

软件仓库主页：[i.nbtca.space](https://i.nbtca.space/)（内网）

::: info 注
下面的清单和链接随镜像站的内容变化。最后核对：2026-08。如果你发现失效的链接或缺漏，请直接修改本页。
:::

## 工具

::: warning 注意
下列工具会修改系统设置或硬件参数：MotionAssistant、MSI Afterburner、Dism++、Win11 修改器、BoosterX、电脑 DCP 优化。不了解每项设置的作用时，不要使用它们。错误的设置会使系统不稳定或不能启动。
:::

### 综合工具包

- 图吧工具箱（[官网](https://www.tbtool.cn)）：免费的硬件检测工具合集，包含常用的硬件检测和跑分工具。

### CPU 工具

- [CINEBENCH_R15](https://www.guru3d.com/download/cinebench-15-download/)：CPU 跑分和压力测试。R15 的负载比 R23 高，用于测试 CPU 的短时稳定性。
- [CINEBENCH_R23](https://www.guru3d.com/download/cinebench-15-download/)：CPU 单核和多核跑分，最常用的版本。R23 可以设定测试时长，用于测试 CPU 的长时间稳定性。
- [MotionAssistant](https://i.nbtca.space/files/%E7%BB%B4%E4%BF%AE%E9%98%9F%E5%B7%A5%E5%85%B7%E5%8C%85/Repair/CPU%E9%94%81%E5%8A%9F%E8%80%97____MotionAssistant.rar)：掌机体感助手，也能限制 CPU 功耗。
