# 故障诊断

本页说明怎样找到一台电脑的故障：开机无显示时的排查顺序，存储故障和内存故障的征兆，系统不能启动时的救援顺序，以及垃圾软件和蓝屏的处理。

找到故障所用的时间通常比修理长。找故障时，先确定故障在硬件、固件还是操作系统中，再在这一层里用替换和排除缩小范围。一次只改一个条件，并使每一步都可以恢复。如果一次改多个条件，修好后你不能确定是哪一步起了作用。

## 开机无显示

按下电源键后，主板按“供电 → CPU → 内存 → 显卡 → 外设”的顺序做开机自检（POST）。按这个顺序从前向后排查：

1. 按下电源键，检查电源灯和键盘背光，听风扇和硬盘有没有声音。
2. 如果没有任何反应，检查供电部件：电源适配器、电池和电源键排线。
3. 如果有反应但屏幕不亮，拔下所有外接设备（U 盘、扩展坞、移动硬盘），再开机。
4. 如果屏幕仍然不亮，接上一台外接显示器。外接显示器有画面而本机屏幕没有画面时，故障在屏幕、屏幕排线或屏轴中，不在主机中。
5. 如果外接显示器也没有画面，拔下电源适配器。如果电池可以拆下，拆下电池。
6. 按住电源键 15 到 30 秒，放掉残余电量，再开机。静电或电源管理故障常使电脑不能开机。
7. 如果仍然不能开机，断电，取下内存条。
8. 用橡皮擦拭内存条的金手指，再装回。
9. 如果有多根内存条，一次只装一根，在每个插槽中逐一测试。
10. 记下台式机的蜂鸣声次数或笔记本指示灯的闪烁次数。这些信号表示自检在哪一步失败。信号的含义由主板厂商决定，查对应型号的手册。

## 存储故障的征兆

::: warning 注意
如果机械硬盘发出有规律的“咔哒”声，立即断电。不要再开机检测。每通电一次，数据损失都会增加。先抢救数据，再检测硬盘。
:::

- **机械硬盘（HDD）**：有规律的“咔哒”声表示磁头不能找到数据。其他征兆是：系统卡顿但 CPU 占用不高；复制文件的速度突然下降；开机时反复进入磁盘修复。
- **固态硬盘（SSD）**：故障前通常没有征兆。常见的故障是：硬盘突然从系统中消失；整个硬盘变成只读；一通电就蓝屏。只有平时的备份能保护固态硬盘上的数据。
- **SMART 属性**：用硬件检测工具（见[软件仓库](./tools)）读取 SMART 属性。检查 `05`（重映射扇区数）、`C5`（当前待映射扇区数）和 `C6`（无法校正扇区数）。如果其中一项不是零并且继续增加，这块硬盘已经损坏，先备份，再更换。

::: warning 注意
怀疑硬盘损坏时，先备份，再检测。全盘扫描和压力测试会使损坏的硬盘更快失效。
:::

## 内存故障的征兆

- 频繁蓝屏，并且每次的错误代码不同，或者反复出现 `MEMORY_MANAGEMENT`。
- 应用程序随机崩溃，或者解压文件时反复校验失败。运行大型程序（游戏、编译）时，这些故障更容易出现。

用排除法找出故障内存：

1. 只装一根内存条，开机。
2. 用 MemTest86 或 Windows 内存诊断完整测试一轮。
3. 换下一根内存条，重复第 1 步和第 2 步。
4. 如果某一根内存条或某一个插槽总是使故障出现，它就是故障部件。

## 系统不能启动

先确定故障在哪一层，再选择工具。始终先抢救数据，再修复系统。

- **能进入系统或安全模式**：
  1. 备份数据。
  2. 如果安全模式能进入而正常模式不能进入，故障通常由驱动或最近的更新造成。逐个回滚最近的更改，找出故障来源。
- **不能进入系统，硬件正常**：
  1. 从 U 盘启动 [PE 系统](/concepts/winpe)。
  2. 把数据复制出来。
  3. 如果故障在引导部分（BCD 丢失、引导分区损坏），从恢复环境（WinRE 或 Windows 安装 U 盘）启动，运行 `bootrec /rebuildbcd` 等命令修复。
  4. 如果不能修复，重装系统。重装通常比继续查找更快，结果也更确定。
- **硬件故障**：按上文的硬件排查顺序检查。硬盘有异响时，先抢救数据，不要反复通电。

## 清除垃圾软件

1. 用 [Geek Uninstaller](/repair/tools) 强制卸载软件。
2. 如果软件不能卸载（例如“360安全管家”），从 U 盘启动 PE 系统，直接删除它的文件。
3. 重启进入本机系统，再用 Geek Uninstaller 清除残留文件。

## 蓝屏

1. 记下蓝屏上的错误代码。
2. 问机主蓝屏前做了什么操作，例如 Windows 更新或驱动更新。
3. 在[微软的错误检查代码参考](https://learn.microsoft.com/zh-cn/windows-hardware/drivers/debugger/bug-check-code-reference2)中查找这个错误代码。
4. 根据错误代码和机主的操作，判断故障来源：
   - **系统文件损坏**：用 Windows 安装 U 盘重装系统。
   - **硬件故障**：按上文“内存故障的征兆”和“存储故障的征兆”测试对应部件。
