# 维修操作指南

本文是维修队的电脑维修操作指南。它包括维修前的安全要求和沟通步骤，并链接到故障诊断、软件维护、物理维护、系统重装和各厂商 BIOS 入口的详细页面。每个维修队成员都要会做这些操作。

本文最早来自 2023 年 3 月戴上博起草的一份 Word 手册，见[维修操作指南（2023 年 Word 版）](/archived/2023/repair-guide-handbook)。[清灰、换硅脂、拆后盖](/repair/physical-maintenance)这几部分仍以它为基础。那份手册的 readme 写着“有意见修正请在 github 中提交”。

## 安全要求

::: danger 警告
拆机前，必须关机、拔下电源适配器，并断开电池排线。通电时操作会造成触电和短路。拆装时注意外壳和散热片的锋利边缘，以免划伤手。
:::

::: warning 注意
重装系统、调整分区和拆机之前，必须备份机主的数据。这些操作可能使数据丢失。
:::

每次操作设备前，回答下面四个问题：

1. 这次操作的目的是什么？
2. 下一步做什么？
3. 哪些步骤可以不做？
4. 上一步有没有做错？

## 维修前的沟通

1. 联系机主，用文字或图片确认机主的需求。
2. 制定维修方案。
3. 把维修方案告诉机主，同时说明机主要做的准备（例如备份数据）和可能的风险。
4. 如果有多个方案，说明每个方案的优点和缺点，让机主选择。
5. 机主同意后，再开始维修。
