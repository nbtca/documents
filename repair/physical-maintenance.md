# 拆机与物理维护

本页说明笔记本电脑的拆机和物理维护：打开后盖、断开电池、清灰、更换硅脂、更换硬盘和内存，以及装回后的测试。

::: danger 警告
拆机前，必须关机并拔下电源适配器。打开后盖后，必须先断开电池排线，再做其他操作。电池通电时，金属工具碰到主板会造成短路。锂电池被刺穿或弯折会起火。
:::

## 准备

1. 关机。不要用睡眠或休眠代替关机。
2. 拔下电源适配器和所有外接设备，包括 USB 设备和 SD 卡。
3. 擦干双手。
4. 触摸接地的金属物体，或戴上防静电手环，释放身上的静电。
5. 如果电池装在机身外部（较老的机型），取下电池。

## 打开后盖

::: warning 注意
不要用金属工具撬后盖，要用塑料撬片。不要把撬片插得太深。金属工具会划伤外壳，插得太深会损坏内部的排线和电池。
:::

1. 用尺寸合适的螺丝刀拆下后盖螺丝。尺寸不合适的螺丝刀会使螺丝滑丝。
2. 把拆下的螺丝按位置分开放进收纳盒。
3. 把撬片插入后盖边缘的缝隙，沿边缘移动撬片，逐个松开卡扣。
4. 如果后盖没有卡扣（部分较老的机型），把后盖向触控板方向推出。

## 断开电池排线

1. 找到电池排线和主板的接口。
2. 如果机器有 LED 灯条，先断开灯条排线。
3. 用镊子或手指断开电池排线。

## 清理风扇

1. 检查风扇和散热鳍片上的积灰。
2. 如果积灰较少，用刷子刷松灰尘，同时用吸尘器吸走。
3. 如果积灰严重，拆下风扇，再清理。

## 更换硅脂

1. 按导热管上标注的数字，从大到小拆下导热管螺丝。
2. 取下导热管。
3. 清除芯片表面和导热管底面的旧硅脂。
4. 确认这两个表面干燥，没有液体残留。
5. 在芯片中央涂半粒米大小的硅脂，再把它涂匀。
6. 装回导热管，按数字从小到大拧紧螺丝。

## 更换或加装硬盘

### M.2 硬盘

1. 拆下硬盘末端的固定螺丝。
2. 把旧硬盘从插槽中拔出。
3. 把新硬盘的金手指斜着插入插槽。
4. 把硬盘末端压平，装上固定螺丝。

### 2.5 英寸 SATA 硬盘

1. 取下硬盘托架。
2. 拆下托架上的螺丝，取出旧硬盘。
3. 把新硬盘装入托架，装回螺丝。
4. 把托架装回机身。

## 更换或加装内存条

1. 同时向两侧拨开插槽的金属卡扣。内存条会向上弹起。
2. 取下旧内存条。
3. 把新内存条金手指上的缺口对准插槽里的凸起。
4. 把内存条斜着插到底，再向下压，直到卡扣发出“咔哒”声并扣住内存条。

## 装回并测试

::: warning 注意
测试完成前，不要拧上后盖螺丝。测试不通过时，你要再次打开后盖。
:::

1. 接回所有排线。最后接电池排线。
2. 合上后盖，轻压边缘，直到所有卡扣扣上。
3. 开机，检查屏幕、键盘、触控板、USB 接口和充电。
4. 所有检查都正常后，拧上后盖螺丝。
