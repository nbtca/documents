# 活动组织

本文说明计算机协会组织一场活动的完整过程：策划、审批、借教室、宣传、人员分工、活动当天的执行，以及会后的学分申报、志愿者时长和报销。每个环节的详细流程见对应的页面。

## 概述

### 办活动的目的

- 为同学提供[第二课堂](/concepts/second-classroom)学分。
- 为同学提供获得[志愿者时长](/concepts/volunteer-hours)的机会。
- 扩大协会的影响。
- 提高成员的组织能力和技术水平。
- 为全校同学服务。

### 计协办过的活动

- 网络安全讲座（电信诈骗）。
- 电脑使用和维护讲座（[CA101](/concepts/ca101)）。
- 电脑[维修日](/repair/repair-day)（免费维修）。

以往活动的经验：

- **CA101 讲座**：面向全校新生，内容是基础的电脑使用技巧和常见问题的处理。需要有投影设备的多媒体教室。安排 1 到 2 名主讲人，时长约两小时。
- **维修日**：计协最有代表性的活动。提前准备工具箱和备用配件（硅脂、螺丝刀套装等），并安排足够的维修人员。通常持续大半天，往届的时间安排见[维修日](/repair/repair-day)。逐项筹备见[维修日检查单](/repair/checklist)。
- **网络安全讲座**：可以邀请校内外专家主讲。提前准备演示设备和网络环境。

## 活动策划

### 确定活动方案

决定举办活动前，确定下面这些事项：

| 事项     | 说明                                                            |
| -------- | --------------------------------------------------------------- |
| 活动目的 | 活动要达到的目标                                                |
| 活动形式 | 讲座、维修日、工作坊、比赛等                                    |
| 目标受众 | 面向社员、面向全校、面向特定学院等                              |
| 时间安排 | 选择不与[考试周](/concepts/school-calendar)、校级活动冲突的时间 |
| 场地需求 | 教室大小、设备要求（参见[借教室流程](./borrow-classroom)）      |
| 人员安排 | 主讲人、现场工作人员、签到人员等                                |
| 预算估计 | 物料费、宣传费等（如有）                                        |

### 撰写策划书

策划书是活动审批的主要材料，提交给校团委或[学院](/concepts/college)团委审批。用协会存档中的<a href="/templates/event/activity-proposal.docx">活动策划书模板</a>起草。策划书包含下面的内容：

1. **活动名称**
2. **主办单位**：浙大宁波理工学院计算机协会
3. **活动背景和目的**
4. **活动时间和地点**
5. **活动流程**：按时间顺序列出每个环节
6. **参与人员**：组织者和预计参与者
7. **物资清单**
8. **预算明细**（如有）
9. **应急预案**：设备故障、人员不足等突发情况的处理方法

写策划书时：

- 参考以往活动的策划书。在协会存档中查找。
- 在时间安排中留出余量。
- 应急预案至少包括主要环节出问题时的替代方案。

### 提交审批

把策划书提交给对应的审批部门：

- **院级活动**：提交给学院团委
- **校级活动**：提交给校团委

::: warning 注意
在活动前至少 5 个工作日提交策划书。审批通常需要 3 到 5 个工作日。审批没有通过时，不能举办活动。
:::

1. 提交策划书。
2. 主动询问审批进度。
3. 如果策划书被退回，按意见修改，再重新提交。

## 活动准备阶段

### 场地准备

借教室的流程见[借教室](./borrow-classroom)。

### 宣传推广

- **线上宣传**：通过协会公众号、QQ 群和朋友圈发布活动信息。
- **线下宣传**：需要时，制作并张贴海报。
- **宣传内容**：活动名称、时间、地点、对象和参与方式。

在活动前 3 到 5 天开始宣传。宣传太早，参与者容易忘记；宣传太晚，知道的人太少。活动前一天，在群里再发一次提醒。

### 物资准备

按活动类型准备物资：

#### 讲座

- 演示文稿（PPT）
- 翻页笔
- 签到表 / 签到二维码
- 饮用水（如有预算）

#### 维修日

- 螺丝刀套装、撬棒等维修工具
- 备用硅脂、散热贴
- 系统安装 U 盘（[PE 系统](/concepts/winpe) + Windows 镜像）
- 签到表 / 登记表
- 维修登记单（记录机主信息和维修内容）

### 人员分工

活动前，确定下面每个角色的负责人：

| 角色         | 职责                               |
| ------------ | ---------------------------------- |
| 活动总负责   | 统筹全局，处理突发情况             |
| 签到人员     | 组织签到，记录出席信息             |
| 主讲人       | 讲座类活动的主讲（如适用）         |
| 现场工作人员 | 维持秩序、引导参与者、协助活动进行 |
| 摄影         | 拍摄活动照片，用于宣传和存档       |

## 活动当天

### 活动前

- [ ] 活动开始前 1 小时，确认教室已经开门。
- [ ] 检查教室设备（投影仪、麦克风、电源等）。
- [ ] 布置场地：摆放桌椅和物资，设置签到台。
- [ ] 确认所有工作人员到场，并清楚自己的任务。
- [ ] 准备签到工具。

### 活动进行中

- [ ] 安排专人负责签到。
- [ ] 按策划书的流程进行活动。
- [ ] 拍摄活动照片，至少包括全景、特写和互动场景。
- [ ] 控制时间，不要严重超时。
- [ ] 出现突发情况时，按应急预案处理。

### 活动结束后

- [ ] 恢复教室原状：桌椅归位，清理垃圾。
- [ ] 关闭教室设备、电源和门窗。
- [ ] 收集并整理签到记录。
- [ ] 清点并归还物资。

## 活动后续工作

### 第二课堂学分申报

活动结束后，负责人整理签到名单，按活动级别向[素拓部或社团部](/concepts/second-classroom-departments)申报。完整步骤、材料清单和所需时间见[申请第二课堂学分](./apply-for-credits)。

### 招募志愿者

1. 填写<a href="/templates/event/volunteer-recruitment.docx">志愿者招募表</a>。写清楚志愿服务的具体内容和时长。
2. 把招募表交给[青协](/concepts/youth-volunteer-association)秘书处。不要等到活动前一天才提交。

### 费用报销

先开发票。开票信息和完整流程见[报销流程](./reimbursement-process)。报销时准备下面的材料：

- 正规发票（电子发票或纸质发票）
- 费用明细清单
- 活动的审批材料

::: warning 注意
花钱之前，必须先获得审批。先花钱再补审批的开支可能不能报销。
:::

- 发票抬头和金额必须与实际支出一致。
- 及时报销，不要拖到学期末。

### 活动总结与存档

活动结束后，完成下面的工作：

1. **写活动总结**：回顾活动情况，记录经验和不足。
2. **整理照片**：选出质量好的照片，用于宣传和存档。
3. **归档材料**：把策划书、签到记录、学分申报材料和照片一起存档。
4. **总结讨论**：与团队成员讨论这次活动的优点和缺点。

## 时间线模板

下表是一个典型活动从策划到完成的时间线：

| 时间节点      | 事项                                   |
| ------------- | -------------------------------------- |
| 活动前 3-4 周 | 确定活动方案，开始撰写策划书           |
| 活动前 2-3 周 | 提交策划书审批，启动教室借用流程       |
| 活动前 1-2 周 | 确认场地，开始宣传推广                 |
| 活动前 1 周   | 确认人员分工，准备物资                 |
| 活动前 3-5 天 | 发布宣传，招募志愿者                   |
| 活动前 1 天   | 最终确认所有准备工作，发送活动提醒     |
| 活动当天      | 执行活动                               |
| 活动后 1-3 天 | 整理签到记录，撰写总结                 |
| 活动后 1-2 周 | 完成学分申报、志愿者时长录入、费用报销 |
